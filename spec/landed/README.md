# Landed sections, one file per work package

`spec/landed/<spec>/WP-NNN.md` is work package WP-NNN's "Landed" section
of `spec/<spec>.md`: what it made the code do, the rules and references,
and the tests by path. The rule, and what `cargo xtask ci` checks about
these files, is in `spec/README.md` "Landed sections".
