# WP-492 — WP-462 follow-ups: `__builtin_expect` at `-O1`, variadic return-adjusting thunks, access groups, constant function-pointer casts, structor asm labels, incomplete-class tracking, `extern` in `extern "C"`

- **`__builtin_expect` above `-O0`** (clang `Builtin::BI__builtin_expect`,
  `BI__builtin_expect_with_probability`): the value and the expected
  value are emitted at every level; at `-O0` the value is the result,
  above it the result is `llvm.expect.T(value, expected)`, or
  `llvm.expect.with.probability.T(value, expected, double P)` whose
  probability the fold prepass evaluates (`builtins::folded_arg`) and
  which is emitted as a `double` constant
  (`tests/codegen/builtin_expect_o1.cpp`, clang 19 and 22).
