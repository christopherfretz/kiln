# WP-584 — C++26 erroneous-value zero init at -O2

**Investigation of the C++26 zero fill (spec/codegen.md §7r). Outcome:
the fill is correct; the failure was an `if consteval` fold in the Oven,
fixed under WP-588 (spec/landed/oven/WP-588.md). This WP adds the tests
below for the shape that exposed it.**

- **Report.** A formatting library's `format("{:08b}", 5)` threw
  `argument not found` when kiln compiled it with `-std=c++26 -O2`;
  `-std=c++23`, `-O0`/`-O1`, `-ftrivial-auto-var-init=uninitialized` or
  `=pattern`, and clang 19 with `-ftrivial-auto-var-init=zero` all
  printed `[00000101]`.
- **Finding.** The zero fill of the failing frame is byte for byte
  clang's. The library's argument-id check reads, under
  `if (is_constant_evaluated() && ...)`, a field of a derived
  compile-time parse context through a `static_cast` of the run-time
  context, i.e. bytes past the object. kiln folded that guard to true
  outside a constant context (the WP-588 bug: libstdc++ implements
  `std::is_constant_evaluated()` with `if consteval`), so the read was
  emitted; it landed in the caller's zero-filled buffer (argument count
  0). With the stack's old contents, or the `0xAA` pattern, the count
  was large and the program happened to work.
- **Minimal shape** (rewritten, `tests/codegen/consteval_if_fold.cpp`):
  ```cpp
  constexpr bool is_ce() { if consteval { return true; } else { return false; } }
  struct ParseCtx { const char *begin; int next_id; void check_id(int); };
  struct CompileCtx : ParseCtx { int num_args; };
  void ParseCtx::check_id(int id) {
    if (is_ce() && sizeof(int) == 4)
      if (id >= static_cast<CompileCtx *>(this)->num_args) fail("argument not found");
  }
  struct Handler { ParseCtx ctx; char buf[24]; };   // `Handler h;` is zero-filled
  ```
  Clang folds the guard to false and emits neither the `num_args` load
  nor the call to `fail`.
- **Tests.** `tests/codegen/consteval_if_fold.cpp` (C++26) and
  `consteval_if_fold_cxx23.cpp` (`-std=c++23
  -ftrivial-auto-var-init=zero`), IR-identical to clang 19 and 22;
  `tests/conformance/basic.indet/run-consteval-guard-zero.cpp` (the
  shape run at `-O2`); `tests/conformance/stmt.if/run-consteval-if-fold.cpp`
  (`-O2` run: constant-initialized globals, `const`/`static`/`constexpr`
  locals, array bound and template argument against run-time `if`, `?:`
  and recursive calls, complementing WP-588's `stmt.if.consteval/`).
