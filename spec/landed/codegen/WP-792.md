# WP-792 — Codegen fixes from the wave 4 constexpr projects

- NEON `__builtin_neon_vpaddl{,q}_v`, `vqdmulh{,q}_v` and `vqrdmulh{,q}_v`
  lower as clang does, to `llvm.aarch64.neon.{u,s}addlp`, `sqdmulh` and
  `sqrdmulh` (`crates/kiln_codegen/src/neon.rs`; spec/codegen.md). The
  UTF-8 validators in daw_json_link (104 TUs) and glaze (3 TUs) reach
  them through `arm_neon.h`. Test:
  `tests/conformance/target.neon/ir-paddl-qdmulh-19.cpp`.
- A vector-typed element of a vector initializer list (`v16 b{a}`, or
  `v4{v2, v2}` shapes kiln accepts) is widened and shuffled in, as clang's
  `VisitInitListExpr`, not inserted as one element
  (`crates/kiln_codegen/src/expr.rs`; spec/codegen.md). glaze's SIMD UTF-8
  validator's default member initializers. Tests:
  `tests/conformance/ext.vector/ir-init-list-vector-element-{19,clang22}.cpp`.
- While an aggregate's initializer list is emitted, `this` in a default
  member initializer (`CXXDefaultInitExpr`) is the object being
  initialized, as clang's `FieldConstructionScope`. Before, kiln used the
  enclosing function's `this`: a `[this]` capture panicked in a free
  function and captured the closure object inside a lambda (glaze's TOML
  `std::function` members test; a wrong-code bug)
  (`crates/kiln_codegen/src/{expr,consts,func,complex}.rs`;
  spec/codegen.md). Test:
  `tests/conformance/dcl.init.aggr/default-member-init-this-in-aggregate.cpp`.
