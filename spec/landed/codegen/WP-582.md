# WP-582 — i0 members in record lowering

A lock-free queue header found in downstream dependencies
emitted `i0` members (invalid IR) for the `Entry*` / `Entry**` fields of
a record nested in a member class of a class template, and silently
dropped that member class's member function bodies.

**Minimal repro** (rewritten; `tests/conformance/temp.mem.class/
member-class-declared-before-definition.cpp`):

```cpp
template <class T> struct Queue {
  struct Producer;                   // declared first ...
  struct Producer {                  // ... then defined
    struct Entry { T key; Entry* next; };
    struct Header { unsigned long capacity; Entry* entries; Entry** index; };
    int sum();                       // body uses Entry / Header
  };
};
```

**Root cause (sema, not codegen).** The pattern member class has two
declarations, so `Queue<int>` instantiates two (`Producer` from the
forward declaration, a redeclaration from the definition). Whichever is
completed first is instantiated from the pattern's definition and records
the nested members (`Entry`, `Header`) in `member_map`; a later lookup
through the pattern's definition maps, via `Queue<int>`'s member map, to
the *other* redeclaration, where `find_member` found nothing. The
resulting `SubstFail` was silent (assumed already diagnosed): field types
became the error type, laid out with no size and lowered to `i0`, and
statements naming the nested types were dropped (a trap at run time).

**Fix.**
- `Substituter::find_instantiated_decl` (`kiln_sema/src/templ/subst/
  mod.rs`) looks the member up in the instantiated parent, then in the
  parent's defined redeclaration (clang's `FindInstantiatedDecl` looks in
  the instantiated context's definition); `find_member_of` keeps the
  first-declaration fallback for out-of-line member redeclarations.
- Guard (`kiln_abi/src/irtype.rs` `IrTypes::builtin`): a builtin with no
  size lowers to `i8`, never `i0` (spec/abi.md §8.6).

**Tests.**
- `tests/conformance/temp.mem.class/member-class-declared-before-
  definition{,-O2}.cpp` (`run`, `strict-diags`): member function bodies
  using the nested types, a forward-declared member `enum class`, and a
  layout-only use (`sizeof` of the nested record and a global of it).
- `tests/codegen/member_class_declared_before_definition.cpp`: the
  nested `Header` is `{ i64, ptr, ptr, ptr }`, IR-identical to clang on
  both triples and both oracles.
