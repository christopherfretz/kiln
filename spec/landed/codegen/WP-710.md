# WP-710 — re2 through its own build and tests (M8 wave 2)

re2 2025-11-05 built with kiln++ through its own CMake build with
`RE2_BUILD_TESTING=ON`, on kiln-built abseil, googletest and benchmark,
and run with CTest (docs/status/oss/re2.md). The behaviour below is the
one kiln bug the build found, reduced to a standalone test; the rule is
stated in the spec named.

## Changes

- **A static member function named with `.`/`->` and not called is its
  function lvalue** ([expr.ref]/6.3.1, [expr.ref]/2; spec/codegen.md
  "Static data members"). `E1.f` where `f` is a static member function, used
  as a value (a comparator passed to `std::sort`, an initializer of a
  function pointer, a function-template argument), evaluates `E1`,
  ignores it, and designates the function; codegen used to reject it as
  "member is not a field".
  Test: `tests/conformance/expr.ref/p6-static-member-function-value-run.cpp`.
- **Harness dependencies** (spec/landed/harness/WP-666.md
  "Dependencies"): `deps` and `install_configure` in
  `scripts/oss/projects.toml`; `oss-build.sh --install PREFIX` builds and
  installs a dependency with the same compiler into
  `.oss/<dep>-install-<compiler>/` and the dependent configures with
  `CMAKE_PREFIX_PATH` on those trees.
