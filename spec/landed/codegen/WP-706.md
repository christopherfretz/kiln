# WP-706 — Contracts are never dropped silently

Until WP-707 evaluates contracts (spec/contracts.md §6.3):

- Under `-fcontract-evaluation-semantic=ignore` codegen emits nothing
  for a `contract_assert` and nothing for a function's `pre`/`post`
  (the predicates are still odr-used, so what they name is emitted).
- Under any checking semantic a function definition with function
  contract specifiers is the error `unsupported: contract evaluation
  (WP-707)` at its first specifier (`func.rs`, not for thunks), and so
  is each `contract_assert` (`stmt.rs`, `CONTRACT_UNSUPPORTED`).

Tests: `crates/kiln_codegen/tests/contracts.rs`,
`tests/conformance/dcl.contract.func/run-ignore.cpp`,
`tests/conformance/stmt.contract.assert/run-ignore.cpp`,
`tests/conformance/stmt.contract.assert/contract-assert.cpp` (xfail).
