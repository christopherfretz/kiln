# WP-665 — Constant-image relocation lookup in logarithmic time

The contract is spec/codegen.md §2 (`consts.rs`). This file records where
the change lives and the tests. Numbers are in
docs/status/perf-reflection.md "WP-665: constant-image relocation
lookup". The emitted IR does not change.

- **Problem.** `crates/kiln_codegen/src/consts.rs` lowers a constant's
  byte image field by field. `Img::reloc` found the relocation at an
  offset with a linear scan of the image's whole relocation table, and it
  ran once for every pointer field and once more for every `i64` or
  literal-struct field (`member_ptr_reloc`, which may find a member
  pointer there). `image_union_member` filtered the whole union table the
  same way for every union. Lowering an image with F fields and R
  relocations cost F x R: quadratic in the length of a constant table of
  pointer-holding structs.
- **Fix.** `Img::reloc` binary-searches the relocations by offset;
  `Img::unions_at` finds the first union member at an offset with a
  partition point and yields the members there in table order, so
  `image_union_member` still picks the first one whose union is the
  requested class. Lowering an image costs O(F log R).
- **Invariant.** Every aggregate image reaches codegen through
  `ConstStore::push_aggregate`, which rejects an image whose relocations
  are not strictly increasing in offset (they cannot overlap and have a
  non-zero width, so at most one starts at an offset) or whose union
  members are not strictly increasing in (offset, field); the Oven's
  freeze sorts both tables before interning. `Img::new` restates the
  invariant as `debug_assert!`s. The answers are therefore the linear
  scans' answers, which the byte-identity runs confirm.
- **Tests.**
  - `tests/codegen/const_table_relocs.cpp` (IR-diff against clang): a
    table of structs holding pointers, function pointers, data and
    function member pointers, unions and nested unions at one offset
    (named by the initializer lists), and a table built by a constexpr
    function (unions whose active members the evaluation recorded). A
    lookup returning a neighbouring relocation, or skipping the first
    union member at an offset, makes kiln's IR differ from clang's or
    fail.
  - `bench/frontend/constant-table-emit.cpp`: the quadratic shape, 8000
    elements and 64,000 relocations.
