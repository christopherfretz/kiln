# WP-792 — Parse: a qualified template name in its own definition

[temp.local]/1: inside the definition of class template `q`, a qualified
name `::n::q` (`::n::q{t, 1}`, or as a decl-specifier) names the
template, not the injected-class-name, so it is a deduced class type
(CTAD placeholder). The expression and decl-specifier paths check
`names_ctad_template` (`crates/kiln_parse/src/{decl,expr,templ}.rs`;
spec/sema-templates.md). mp-units rejected 31 TUs at `quantity.h:205`.
Test: `tests/conformance/temp.local/qualified-name-in-own-definition-ctad.cpp`.
