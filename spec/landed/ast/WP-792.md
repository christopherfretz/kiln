# WP-792 — AST: profiling a reference to a specialization

A `DeclRefExpr` or `MemberExpr` naming a specialization with
non-dependent written template arguments is profiled by the
specialization alone, as clang's canonical `VisitDeclRefExpr`; dependent
argument lists and references to a template keep their arguments
(`crates/kiln_ast/src/types/profile_expr.rs`; spec/types.md). Before,
the non-dependent argument expressions had no profile and compared by
id, so `requires(M != mag<1>)` repeated on a redeclaration was a
different requires-clause (mp-units `scaled_unit`). Test:
`tests/conformance/temp.over.link/requires-clause-specialization-reference.cpp`.
