# WP-972 — ICE audit of kiln_ast's panicking sites

WP-911 counted the panicking sites a user translation unit might reach.
This package triaged every `expect`/`unwrap`/`unreachable!`/`panic!`/
`assert!` and panicking index in `crates/kiln_ast/src` (non-test code).
Each site is either (a) an internal invariant, which stays but now names
the invariant in its message, or (b) reachable from user input, which
must degrade to a diagnostic or a recovery node.

## The crash that was found: `token_end` at EOF (kiln_sema)

The only user-reachable crash was outside kiln_ast. Sema's
`impcast::token_end` measured the token starting at a location. When a
`sizeof(`/`alignof(` type operand's `)` was missing at the end of the file,
the location was the end-of-file location, and the punctuator branch
stepped past the buffer. `SourceManager::loc` then panicked
(`offset N past end of FileId`). It now returns `None` for a location at or
past the end of the buffer, and its callers already fall back to the
`)` location. Tests:
`tests/conformance/expr.alignof/missing-rparen-at-eof.cpp` and
`tests/conformance/expr.sizeof/missing-rparen-at-eof.cpp`. Both files end
without a final newline: clang puts the EOF token on that newline and kiln
puts it after it, so with a newline the `)` diagnostic's line:col would
differ.

## Sweeps (panic counts before → after)

- **`cargo xtask clang-neg` over CXX, SemaCXX, SemaTemplate and Parser
  (llvmorg-22.1.8):** 3389 cases. Before: 0 crashes, 0 timeouts,
  0 OOM. After: 0.
- **Every `.cpp` in those directories, compiled with `-fsyntax-only` at
  `-std=c++26`, `gnu++17` and `c++98`:** 0 ICEs (before the fix; the
  clang-neg run after it covers the same files).
- **Mutation fuzzing of the same files:** truncation, token deletion and
  duplication, line drop and duplication, and inserted or replaced GNU,
  statement-expression, reflection, contracts and coroutine tokens.
  - Round 1 (≈18,000 mutants): 22 ICEs, all of them `token_end` at EOF.
  - After the fix, all 22 repros compile without an ICE.
  - Round 2 (≈28,000 mutants, seed 2, with the fix): 0 ICEs.
- **Hand probes:** about 90 error-recovery and edge-case TUs (broken
  declarators and template ids, GNU extensions, designated and odd
  initializers, anonymous members, redeclaration kinds, reflection,
  contracts, coroutines). 0 ICEs.

xtask has no fuzz or reduce helper, so there was no such tool to sweep.
