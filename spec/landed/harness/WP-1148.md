# WP-1148 — C++20 module rows in the OSS harness

The M8 harness (spec/landed/harness/WP-666.md) builds CMake projects that
use C++20 named modules: CMake needs Ninja and a dependency scanner for
them, and kiln provides the scanner as kiln-scan-deps (spec/modules.md
§11.9, spec/driver.md "Dependency scanning"). The results are in
docs/status/oss/fmt_module.md and docs/status/oss/cmake_modules.md.

## Landed

- `projects.toml` key `modules` (default false; cmake rows). On such a
  row `oss-build.sh` requires `cmake` and `ninja`, configures with
  `-G Ninja` and `-DCMAKE_CXX_COMPILER_CLANG_SCAN_DEPS=<scanner>`, and
  builds with `ninja -k 0 -j <n>` (after `ninja -t clean`) instead of
  `make -k`. The scanner is `kiln-scan-deps` beside kiln++ for
  `--compiler kiln`, and the `clang-scan-deps` named like the control
  compiler (`clang++-19` → `clang-scan-deps-19`) beside it for
  `--compiler clang`; a missing scanner exits 2. It is passed explicitly
  because, with the `kiln-cxx` wrapper as the compiler, CMake would find
  the system's clang-scan-deps. The scanner runs without the wrapper,
  so with `--stdlib libc++` the configure also passes
  `-DCMAKE_CXX_FLAGS=-stdlib=libc++`. Ninja 1.12 is not a jobserver
  client, so the job count is capped at 4. The log line
  `oss-build: modules: Ninja <version>, scanner <path>` names both.
  Rows without `modules` are unchanged (Unix Makefiles, `make -k`).
- `projects.toml` key `local` (a directory relative to `scripts/oss/`):
  the row builds that directory in place, with no clone or archive;
  `url` defaults to empty and `tag` to `local`.
- `kiln-cxx` counts module interface units (`.cppm`, `.ccm`, `.cxxm`,
  `.c++m`, `.ixx`, `.mpp`) as TUs; they were logged as source `none`.
- The `fmt_module` row: {fmt} 12.1.0 with `FMT_MODULE=ON`, `FMT_TEST=OFF`,
  and `-DCMAKE_PROJECT_FMT_INCLUDE=@OSS@/shims/fmt-module-tests.cmake`.
  The shim defers, to the end of fmt's top-level CMakeLists.txt, the
  importer `fmt-module-smoke` (`shims/fmt-module-smoke.cc`: `import
  fmt;`, 14 checked formatting cases), its CTest case and the target
  `fmt_module_tests`; `enable_testing()` is at the shim's top level,
  since CTest files are written only for directories that enabled
  testing while configured. The test is `ctest --no-tests=error`.
- The `cmake_modules` row: `local = "fixtures/modules"` (the
  `selftest.sh` fixture), checked by running `app`, and `stdapp`
  (`import std;`) where CMake built it (libc++).
- `fixtures/modules/CMakeLists.txt` adds `-fmodules-reduced-bmi` only
  for compiler versions 20 and later (clang 19, the control, rejects it).
- Provisioning: `ninja-build` (Ninja) and `clang-tools-19`
  (clang-scan-deps-19, the control's scanner).
