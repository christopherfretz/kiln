# WP-1034 — CI runs the capability tests it used to skip

Three groups of tests passed locally but never ran in GitHub CI: the
`requires: sanitizer-runtime` run tests (no compiler-rt in the image,
WP-1045), the CMake modules end-to-end of `scripts/oss/selftest.sh`
(WP-982; no CMake 3.28 or ninja), and the Itanium mangling differential
behind `cargo xtask test tests/mangle` (WP-1031; that command compiled
the files but never compared symbols, and a missing clang++-19 skipped
the differential silently). docs/VALIDATION.md "GitHub Actions" says
what now runs where.

## Landed

- `.github/actions/kiln-ci/action.yml`: inputs `sanitizer-runtimes`
  (installs `libclang-rt-19-dev libclang-rt-22-dev` and prints both
  runtime dirs) and `cmake` (installs `cmake ninja-build` and prints the
  versions), both default `"false"`.
- `.github/workflows/ci-lane.yml`: lane env
  `KILN_REQUIRE_SANITIZER_RUNTIME: "1"`; `self-check`, `kiln-22` and
  `kiln-19` pass `sanitizer-runtimes: "true"`; `kiln-22` passes
  `cmake: "${{ matrix.shard == 1 }}"` and, in shard 1 after the corpus
  step, runs `KILN_OSS_CXX=$PWD/target/debug/kiln++
  scripts/oss/selftest.sh --cmake-modules`.
- Harness: `KILN_REQUIRE_SANITIZER_RUNTIME=1` (`test::Options::
  require_sanitizer_runtime`, `runner::Config::require_sanitizer_runtime`,
  `sanitizer_runtime_gate`) turns the missing-runtime SKIP into an ERROR,
  as `KILN_REQUIRE_DEBUGGERS` does for the debuggers (spec/harness.md
  "Directives"); `cargo xtask ci` passes it to both corpus runs.
- `cargo xtask ci`'s `unit` step (whole workspace, or the `codegen`
  group) runs `cargo test ... -- --skip mangling_matches_clang` and then
  `cargo test -p kiln_codegen --test mangle_vs_clang -- --nocapture`
  (`MANGLE_TEST`), so the per-triple counts reach the log; `ci --quick`
  runs it too (about 3 s).
- `cargo xtask test` without `--compiler` runs the same command after the
  corpus when a path names `tests/mangle` (`names_mangle_corpus`); a
  failure is exit 1 (spec/harness.md "The mangling differential").
- `mangle_vs_clang` and `abi_run_vs_clang`: a missing clang++-19 under
  `KILN_REQUIRE_LLVM=1` is a failure, not a skip; `mangle_vs_clang`
  prints `<files> files, <n> clang symbols checked` per triple.
- `scripts/oss/selftest.sh --cmake-modules`: only the CMake modules
  check, FAILing (not SKIPping) without CMake 3.28, ninja or kiln++, with
  the configure/build/rebuild log tails on failure; any other argument is
  a usage error (exit 2).
- Tests: `runner::compat_tests::sanitizer_runtime_gate_skips_or_errors`,
  `test::tests::mangle_corpus_paths`, `ci_tests::cargo_steps`,
  `ci_tests::workflow_installs_the_sanitizer_runtimes`,
  `ci_tests::workflow_runs_the_cmake_modules_e2e`.
