# WP-488 — CI runtime: oracle-only second pass, per-WP Landed files

- **`cargo xtask ci --oracle-only`** ("CI"): the second oracle's gate
  (`KILN_ORACLE=19 cargo xtask ci --quick --oracle-only` in
  `.github/actions/kiln-ci/action.yml`) skips step 0, fmt and clippy, and
  runs of `cargo test` only the targets in `ORACLE_TESTS`
  (`xtask/src/main.rs`), then the kiln build and the corpus as before.
  Before it, the second pass reran fmt, clippy and the whole workspace
  test set, all independent of `KILN_ORACLE`, for 3.5 min per job.
  `Options::toolchain` lets the harness's own tests pin release 19
  (`clang_opts`), so they no longer read `KILN_ORACLE` through
  `requires: llvm`.
- **Step 0 lint for `spec/landed/`** (`xtask/src/landed.rs`,
  spec/README.md "Landed sections"): path shape, title line and
  `docs/BACKLOG.md` row.
- **Slow tests**: `seed_corpus_passes_with_clang` runs the hand-written
  corpus at the default `-j` rather than two jobs (it was 85 % of the
  xtask binary; its static directive-coverage check is now the separate
  `seed_corpus_exercises_every_directive`, which needs no clang), and
  `ir_vs_clang`'s `ir_matches_clang` compiles its cases
  on `RUST_TEST_THREADS` (default: available CPUs) worker threads, with
  results accounted in the same order as before.

Tests: `xtask/src/main.rs` `ci_tests::oracle_tests_are_listed` (every
file under `crates/` that reads `KILN_ORACLE` is a listed target, and
every listed target reads it), `ci_tests::cargo_steps`;
`xtask/src/landed.rs` `tests::well_formed_files_pass`,
`tests::problems_are_listed`, `tests::wp_ids`.
