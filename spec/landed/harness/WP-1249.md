# WP-1249 — `cargo xtask test --compiler $KILN_GCC` is usable

Briefs tell implementers to check reflection and contracts tests with GCC
16.1 as the compiler under test, but that mode passed GCC kiln's and
clang's flags (`--gcc-toolchain=`, which g++ rejects), checked kiln's
`diag:` wording against GCC's, and compiled kiln's own `kiln_meta.h`
(kiln intrinsics) with GCC. spec/harness.md "GCC as the compiler under
test" now defines what such a run checks, per test kind.

## Landed

- `xtask/src/test/runner.rs`:
  - `command()` maps the mode flags and the test's `args` through
    `oracle::gcc_args` when the compiler under test is a GCC (the GCC
    oracle's mapping, not a copy). It also puts
    `-I<repo_root>/tests/support/meta-header` (the header-differential
    mode's stand-in `kiln_meta.h`, over GCC's own `<meta>`) first, and
    appends `-lstdc++exp` to a compile that links (`gcc_links`), since
    GCC keeps the default contract-violation handler there.
  - `check_diags` takes its directives from `diag_directives_for`, which
    gives `None` under GCC: `diag:` and `strict-diags` are not checked.
  - `mode_skip` skips a test that includes `kiln_meta*.h` under GCC for
    the header-differential mode's reasons (`stand_in_skip`, shared with
    `meta_header_skip`; prefix `GCC under test: `). `meta-header: skip`
    applies there too.
- `xtask/fixtures/fake-gcc/g++` rejects `--gcc-toolchain=`,
  `-ferror-limit=`, `-fclang-compat=` and `-fkiln-*` as GCC does.
  `xtask/fixtures/gcc-compiler/` holds 9 fixtures for the mode.
- Unit tests: `gcc_under_test_gets_gcc_spelling`,
  `diag_directives_per_compiler_kind`, `gcc_links_unless_compile_only`
  and `gcc_under_test_stand_in_skip` (runner.rs);
  `gcc_as_the_compiler_under_test` (tests.rs).
- 34 corpus tests carry `xfail(gcc): <reason>` for a known GCC 16.1
  disagreement (most already documented in their comments and in
  spec/contracts.md §9).
