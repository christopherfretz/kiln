# WP-695 — google/benchmark through its own build and tests (M8 wave 2)

google/benchmark v1.9.5 built with kiln++ through its own CMake build and
ctest suite (docs/status/oss/benchmark.md). Each fixed behaviour below is
a kiln bug the build found, reduced to a standalone conformance test; the
rule is stated in the spec named.

## Changes

- **A parenthesized function template-id that is called stays an
  overload set** ([temp.arg.explicit]/4, [over.call.func]/3,
  [over.over]/3; spec/sema-overload.md §2, function template-ids).
  `(f<A>)(x)` and `((f<A>))(x)` deduce the remaining template arguments
  from the call, as `f<A>(x)` does; kiln resolved the parenthesized
  template-id to the specialization with only the explicit arguments
  (a trailing pack deduced empty), rejected the call with "too many
  arguments to function call" and instantiated that specialization. The
  parentheses now also stay in the AST around a callee resolved by
  overload resolution (`(f)(x)`), as in clang.
  Test: `tests/conformance/temp.arg.explicit/parenthesized-template-id-callee.cpp`.
