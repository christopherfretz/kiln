# WP-661 — Redeclaration and overload constant factors: explicit-argument memo, memory rows

This WP changes spec/sema-templates.md §6.1 (the "Explicit-argument memo
(WP-661)" bullet under Shortcuts), spec/sema-overload.md (accounting
rows) and spec/ast.md §14 (journal rows). The measurements, the ranking
of the seven candidate items and the A/B tables are in
docs/status/perf-reflection.md, in the section "WP-661:
redeclaration and overload constant factors" (follow-up rows F13, F14).

Nothing observable changes. The following stay byte-identical: every
diagnostic and note and their order, the previous declaration each
declaration redeclares, the overload resolution and deduction outcomes,
the instantiation report's rows (counts, nodes, bytes), the AST and the
emitted IR.

## Changes

- **Explicit-argument memo** (`kiln_sema/src/templ/explicit_memo.rs`,
  used in `templ/deduce_call.rs` step 1).
  - Key: the function template's `DeclId` and the explicit template
    argument types (up to four; more are never memoized). Value: the
    substituted parameter types.
  - Direct-mapped, 2,048 slots of 56 bytes (112 KiB), allocated on the
    first kept result; a collision overwrites.
  - The `ExplicitTemplateArgumentSubstitution` frame is pushed and popped
    on every attempt, hit or miss, so the instantiation report keeps
    every row.
  - A result is kept only if the substitution succeeded with no SFINAE
    error, held back or emitted no diagnostic, created no AST node and
    no node bytes, and pushed no instantiation frame of its own, and the
    template is not declared in a local scope. A failure is never kept,
    so each failure's notes and diagnostics come again at the same point,
    once per attempt.
  - Off under `Sema::full_deduction` (`ParseOptions::full_deduction`).
- **Memory rows.** `Sema::overload_memory` gains `sema.redecl_index`
  (count = keyed positions) and `sema.explicit_memo` (count = slots in
  use; bytes = the table). `Ast::memory` gains `journal.lookup`,
  `journal.decl_types` and `journal.redecls` (`Journal::mem_row`). The
  journals stay outside the per-instantiation node meter.
- **Counters** (`op-stats`): explicit-substitution attempts, repeat keys,
  memo hits and answers; journal events per sync, by kind.

## Measured and not landed

- A per-`DeclId` cache of `fn_min_args` answered 94–97% of calls but cost
  more instructions than the parameter walk it replaced (+0.07% Ir on
  S8 N=100). `fn_min_args` is unchanged.
- The member redeclaration arm and `find_prev_function` through the
  redeclaration index, a position index for
  `LookupTables::insert_with_flags`, and a generation counter for the
  index's sync each measured under 0.3% of every shape. The index's
  scope is unchanged (spec/sema.md §3).

## Test-only entries

`crates/kiln_parse/tests/deduction_prefilter.rs`:
`explicit_argument_memo_matches_the_full_path` compiles calls with
explicit template arguments (repeats, failures, a SFINAE failure, an
error inside the substituted declaration) with and without
`full_deduction` and asserts equal diagnostics and equal instantiation
reports (timings stripped); `min_args_follow_added_default_arguments`
covers default arguments added by redeclarations, out-of-class member
definitions and late-parsed class members. `crates/kiln_parse/tests/
redecl_index.rs`: `memory_rows_report_the_index_and_the_memo`.
