# WP-465 — WP-445 follow-ups: wide `_BitInt` and friends

- **Wide `_BitInt` in memory** (`kiln_abi/src/irtype.rs`, `kiln_codegen`):
  a `_BitInt(N)` whose `iN` allocates a different size than clang's
  layout is a byte array in records and memory, loaded and stored as the
  integer of its size, as clang 22 does on aarch64 and x86_64.
- **Wide `_BitInt` in the Oven and sema** (`kiln_oven/src/compile/wide.rs`,
  `vm/wide.rs`): float conversions, bit-fields, `switch`, `<=>`, literals
  and non-type template values over 128 bits; `-Wdivision-by-zero` and
  bit-field truncation warnings for wide values.
- **Case values** are converted constant expressions ([stmt.switch]/2):
  `case 1.5:` is the converted-constant error, not a conversion warning.
- **Braced functional cast**: a narrowed element gets the narrowing
  diagnostic only, not also `-Wliteral-conversion`.
- **`FF{}` of a function type** is the function-type construction error;
  a `const_cast` write to a const local is the Oven's modification note.
- **`__builtin_is_within_lifetime`** (spec/oven.md): virtual bases are
  tracked by the most-derived constructor's steps; a consteval
  constructor handed a pointer to the constexpr/constinit variable it
  initializes (`constexpr C c(&c)`, `C(&c)`, `{&c}`) fails as kind 3,
  reported after the variable's own check (spec/sema.md); the elements of
  a list-initialized member (aggregate or array) are tracked in order.
- **NTTP deferral** (spec/sema-templates.md §3.1): instantiation-dependence
  only in an operand type (`sizeof(void_t<decltype(e)>*)`, `alignof`, a
  type trait's operands) keeps the argument as written; its canonical
  form is its converted value.
