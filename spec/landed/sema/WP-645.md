# WP-645 — Allocation churn, the boxed Oven and an allocation-free node meter

Extends spec/sema.md §8.1 (the Oven's placement), spec/sema-templates.md
R-OVEN-1 and spec/ast.md §2.3 (the instantiation node meter). The
measurements, before/after counts and A/B tables are in
docs/status/perf-reflection.md "WP-645: allocation churn"
(follow-up rows F5, F6, F12). Nothing observable changes: diagnostics,
the AST dump, the IR and the `-fkiln-instantiation-report` output are
byte-identical, and every walk keeps its visiting order.

## The Oven is boxed (F6)

`Sema.oven` and `Sema.spare_oven` are `Option<Box<Oven>>`. `with_oven`
takes the box out of `Sema.oven` and puts it back, so each evaluation
moves a pointer instead of the evaluator (about 430 instructions of
`memcpy` per call before). `lend_oven` swaps the loaned Oven's contents
with the spare box as before (R-OVEN-1).

## The node meter allocates nothing (F12)

`Ast::node_live_bytes` runs at every instantiation-frame push and pop.
The annotation, attribute, redeclaration and lookup arenas computed their
part through `MemRow` (a `String` name per row). They now sum
`kiln_ast::VecDims` and `kiln_ast::mem::map_live_bytes` /
`ColdMap::live_bytes`, the numbers their `heap_bytes` rows report.
`crates/kiln_ast/src/lookup.rs` tests pin the equality of the meter and
the rows.

## Scratch buffers and in-place walks (F5)

- **Expression children.** `ExprArena::children_each` enumerates the
  children into any `Extend` sink; `children_into` appends to a caller's
  `Vec` and `first_child` returns the first child without a `Vec`. Every
  worklist walk that did `stack.extend(children(x))` appends in place
  (same order); `Ast::begin_loc` and the other first-child loops use
  `first_child`.
- **Full-expression walks.** `decl_refs_in`, `has_own_temporaries`,
  `note_shared_temporaries`, `mark_shared_expr_referenced`,
  `recheck_enum_constants_in_bool` and `check_implicit_conversions` take
  Sema's scratch stacks (`Sema::take_walk_stack` / `put_walk_stack`,
  `conv_walk_stack`): cleared at take, put back after the walk. A walk
  that re-enters another one while it holds the stack gets a fresh
  `Vec` (the cell is empty), so nesting is safe.
- **Usual arithmetic conversions.** `common_sugar`
  (`conv/arith.rs`) finds the first node of one operand's desugaring
  chain that is on the other's by walking both chains, with the same
  256-step bound, instead of collecting them.
- **Lookup.** `Sema::filter` takes any iterator of `DeclId`s; the class,
  block, function and namespace scopes pass the lookup table's iterator
  (namespace scope chains it with the using-directive results, in the
  same order: own declarations first, then each nominated namespace's in
  directive order, [namespace.udir]/2).
- **Template heads and constraints.** `heads_equivalent` zips the two
  parameter lists; `Sema::exprs_equivalent` profiles both expressions
  into Sema's reused `kiln_ast::EquivScratch`
  (`Ast::exprs_equivalent_in`).
- **Special members.** `special_fields_iter` yields the fields
  `special_fields` collects; `call_subobjects` and
  `exc_spec_needs_unparsed_inits` iterate it.
- **Argument lists.** `TypeContext::arg_list` builds the canonical copy
  only when an argument is not canonical.
- **Declarator names.** The declarator-to-type walk spells the
  declarator's name only when it issues a diagnostic.

## Tests

No new behaviour, so no new corpus tests. Pinning: the existing corpus
(`cargo xtask ci --quick`), the crate tests (`cargo test -p kiln_ast -p
kiln_sema -p kiln_oven -p kiln_codegen -p kiln_llvm`), and the
`-fkiln-instantiation-report` corpus tests, which are byte-identical.
