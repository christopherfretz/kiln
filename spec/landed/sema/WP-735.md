# WP-735 — correctness bundle: seven corpus-found parse/sema gaps

The M8 corpus agents filed these as follow-ups (WP-708, 712, 713, 714,
715, 722, 723). Each is reduced to a standalone test checked against
clang 19 and 22; the rule is stated in the spec named.

## Changes

- **Dependent `noexcept(expr)` in a type is substituted**
  ([except.spec]/13, [temp.inst]/14; spec/sema-templates.md). The
  canonical `ExcSpec::DependentNoexcept` of a function type (under a
  pointer, member pointer, reference or GNU `noreturn`) is rebuilt from
  its operand at instantiation, and deduction from a conversion function
  template to a pointer to function allows the `noexcept`-dropping
  function pointer conversion ([temp.deduct.conv]/5) (WP-723).
  Tests: `tests/conformance/except.spec/p13-dependent-noexcept-gnu-noreturn-subst-run.cpp`,
  `tests/conformance/temp.deduct.conv/p5-noexcept-function-pointer-conversion-run.cpp`.
- **Global `operator new` templates are allocation candidates**
  ([expr.new]/20, [temp.over]/1; spec/sema-overload.md). They take part
  in overload resolution with the non-template functions, deduced from
  the placement arguments; with none viable the notes list the
  template candidates (WP-712).
  Tests: `tests/conformance/expr.new/p20-global-operator-new-template-run.cpp`,
  `tests/conformance/expr.new/p20-global-operator-new-template-no-viable.cpp`.
- **Placement `operator delete` templates match** ([expr.new]/28;
  spec/sema-overload.md), by deduction against `void(void*, P...)` from
  the allocation function's parameters (WP-713).
  Test: `tests/conformance/expr.new/p28-placement-delete-template-run.cpp`.
- **`D::B::m` through a base's injected-class-name** ([temp.local]/2,
  [class.qual]/2; spec/parse.md), also through a dependent base (WP-714).
  Test: `tests/conformance/temp.local/p2-base-injected-name-nested-name-specifier-run.cpp`.
- **`&N::f` naming an overload set through a dependent base** stays the
  qualified set and is resolved at instantiation against the target type
  ([expr.unary.op]/3, [over.over]; spec/sema-templates.md) (WP-715).
  Tests: `tests/conformance/expr.unary.op/p3-qualified-overload-set-dependent-base-run.cpp`,
  `tests/conformance/expr.unary.op/p3-qualified-overload-set-dependent-base-mismatch.cpp`.
- **`throw(Ts...)` pack expansions** ([except.spec]/1 before C++17,
  [temp.variadic]/5; spec/parse.md); an empty expansion is `throw()`,
  and C++17 rejects the form as any dynamic specification (WP-722).
  Tests: `tests/conformance/except.spec/p1-dynamic-pack-expansion-run.cpp`,
  `tests/conformance/except.spec/p1-dynamic-pack-expansion-cxx17.cpp`.
- **GNU `noreturn` after a grouping `(` and in type-ids**
  ([dcl.decl.general]/4, [dcl.ptr]/1; spec/types.md §5.4, spec/parse.md):
  `void (__attribute__((noreturn)) *fp)(int)` and
  `using F = void (*__attribute__((noreturn)))(int)` declare a pointer to
  a noreturn function, as in clang (WP-708).
  Tests: `tests/conformance/dcl.attr.noreturn/gnu-noreturn-declarator-positions.cpp`,
  `tests/conformance/dcl.attr.noreturn/gnu-noreturn-declarator-positions-run.cpp`.
