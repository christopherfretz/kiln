# WP-1301 — C mode: closing the gcc.c-torture gap with clang 19

C mode wave 2c, after WP-1286. It ranks the gcc.c-torture cases that clang 19 passes and kiln does not (docs/status/c-mode.md) and fixes the clusters that remain once WP-1286 is in. The oracle is clang 19 `-x c` at `-fclang-compat=19`, wording and locations included. Every C rule is gated on `Sema::is_c()`; the two parser fixes also apply to C++, as in clang. The rules are in spec/sema.md §1.0.1 and §1.0.2.

- **GNU attributes on a later declarator** (`kiln_parse` `decl.rs` `parse_simple_declaration_delayed`, `class.rs` member loop; clang `ParseDeclGroup`, `ParseCXXClassMemberDeclaration`). Tests: `tests/conformance/dcl.attr.grammar/gnu-attributes-on-later-declarator.cpp`, `tests/c/parse/gnu-attributes-on-later-declarator.c`.
- **`common` on a C variable** (`internal_linkage.rs`, `Ast::has_common_attr`, `kiln_codegen` `module.rs`): kept in C, with common linkage for a tentative definition. Test: `tests/c/run/common-attribute.c` (two units).
- **`_Alignas` after a type specifier** (`kiln_parse` `decl.rs` `parse_decl_specifiers`). Test: `tests/c/decl/alignas-after-type-specifier.c`.
- **Implicit declarations of predefined library functions** (`builtins.rs` `c_implicit_lib_function_decl`, `kiln_ast` `builtin::lib_header`, `templ/actions.rs`; new ids `sema_implicit_lib_function_decl_c99`, `sema_incompatible_library_redecl`, group `IncompatibleLibraryRedeclaration`), and the redeclaration warning (`decl.rs` function merge; `c_no_proto_composite` is quiet after an implicit declaration). gcc.c-torture execute/941202-1.c. Tests: `tests/c/decl/implicit-library-function-{c89,c99}.c`, `tests/c/run/implicit-library-function-gnu89.c`.
- **Transparent union parameters in redeclarations** (`transparent_union.rs` `c_transparent_param_merge`, `c_decl.rs` `c_proto_composite`, `conv/c_assign.rs`, `kiln_codegen` `func.rs` prologue, `kiln_abi::call::transparent_union_first_field`). gcc.c-torture compile/pr34885.c, pr46866.c. Test: `tests/c/decl/transparent-union-redeclaration.c`, flipped from the WP-1286 xfail.
