# WP-629 — sema: a defaulted template parameter after a parameter pack is absorbed into the pack on an unqualified call inside a class template

[temp.deduct.call]/1, [temp.param]/14, [temp.arg.explicit]/9. A call of a
member function template from a member of a class template, resolved at
the definition, is named again in the instantiated class by
`respecialized_member_template` (`templ/subst/exprs.rs`). It re-read the
specialization's arguments, flattened, as explicit template arguments, so
for `template <class... Args, class E = int>` the deduced `Args = <>` and
`E = int` became the explicit list `<int>`, all of it taken by the pack.
When the template has a non-trailing pack, the substituted structured
argument list now forms the specialization directly
(`structural_member_spec`). The rule is in `spec/sema.md` §5.21 and
`spec/sema-templates.md` (atomic constraints, `respecialized_member_template`).
