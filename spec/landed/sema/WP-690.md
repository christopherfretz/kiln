# WP-690 — EnTT v3.15.0 with kiln++

WP-690 builds EnTT v3.15.0 and its googletest suite through its own CMake
build, using `scripts/oss`. The results are in docs/status/oss/entt.md.
Each fixed behaviour below has a test and a sentence in the spec that
owns it.

## Fixed behaviours

- **A default argument of a dependent class type waits for its
  instantiation** ([dcl.fct.default]/5, [temp.dep.type]/7,
  [temp.inst]/12). A parameter of (reference to) a nested class of a
  class template keeps its default argument as written; it is converted
  when a call instantiates it. Before, kiln converted it in the template
  definition, where the nested class's default member initializers are
  "needed within the definition of the enclosing class", and the
  instantiation then failed on the converted `InitListExpr`. EnTT's
  `locator<T>::reset(const node_type &other = {})` is this shape.
  - Spec: spec/sema-templates.md §6.4, default function arguments.
  - Tests: tests/conformance/dcl.fct.default/nested-class-of-template.cpp
    and nested-class-of-template-error.cpp.
