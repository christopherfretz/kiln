# WP-958 — rejects-valid: templates, deduction, classes (clusters 15, 16)

Fixes the rejects-valid repros of docs/status/accepts-invalid.md clusters 15
and 16 (WP-912's clang negative-test run), each matched against clang 19
(clang 22 where the test pins it). None was deferred. The two cluster-16
repros owned by WP-962 (`dcl.init.list/empty-initializer-list-no-default-ctor.cpp`,
`expr.const/duffs-device.cpp`) are untouched.

## Templates and deduction (cluster 15)

- **Lexical substitution order** (spec/sema-templates.md §5.6): a leading
  return type is substituted before the parameter types, so its failure
  stops substitution ([temp.deduct.general]/7); a trailing one still
  follows them. Tests: `temp.deduct/return-type-failure-before-parameters.cpp`,
  `temp.deduct/trailing-return-substituted-after-parameters.cpp`.
- **Subsumption from one clause form** (§8.4): `subsumes_by` builds DNF(P),
  else CNF(Q), and evaluates the other side monotonically (memoized per
  node), instead of needing both under one 65,536-clause cap.
  **Normalization depth** (§8.2): parentheses and `&&`/`||` operands no
  longer count toward `MAX_EXPANSION`; only concept-ids and folds do.
  `large-normal-form-subsumption.cpp` was a hard limit plus a wrong normal
  form, not a perf cliff: an 80-operand `||` became an atom past operand 64.
  Debug kiln++, before: 0.10 s / 22 MB with the wrong ambiguity; after:
  0.12 s / 20 MB, correct (clang 22: 0.04 s / 88 MB; clang 19: 32 s /
  26.9 GB). Test: `temp.constr.order/wide-normal-form-other-side.cpp`.
- **References are potentially-constant** ([expr.const]/3, `builder.rs`):
  a reference initialized with a value-dependent constant is
  value-dependent. Test: `temp.dep.constexpr/reference-to-value-dependent-constant-assert.cpp`.
- **Member templates of a specialization** (§6.8): an out-of-line
  redeclaration's constraints are compared with the specialization's
  member template constraints substituted with the outer arguments
  (`member_cmp_constraints`, through `friend_cmp_constraints`). Tests:
  `temp.expl.spec/member-template-constraints-{substituted,mismatch}.cpp`.
- **`decltype` of a reference NTTP of class type** keeps the reference:
  `SubstNonTypeTemplateParmExpr` carries `ExprFlags::REFERENCE_PARAMETER`
  (clang `isReferenceParameter`). Test: `dcl.type.decltype/reference-nttp-class-type.cpp`.
- **Partial matching**: a deduced integral value that its parameter's type
  cannot represent fails the match ([temp.arg.nontype]/1). Test:
  `temp.spec.partial.match/narrowing-nttp-deduced-types.cpp`.
- **Partial ordering**: a `P` pack-expansion pattern is deduced from an
  `A` pack-expansion pattern ([temp.deduct.partial]/8). Test:
  `temp.spec.partial.order/pack-expansion-pattern-more-specialized.cpp`.
- **Explicit packs** stay extendable by deduction ([temp.arg.explicit]/9),
  also inside template-ids. Tests:
  `temp.arg.explicit/pack-explicit-{extended-in-template-id,param-stays-dependent}.cpp`.
- **`typename T::X x = e;`** naming a member class template is a
  placeholder for a deduced class type ([dcl.type.class.deduct]/1), only
  as a variable's whole declared type (clang `err_deduced_tst` otherwise).
  Tests: `dcl.type.class.deduct/typename-member-class-template-{deduces,pointer}.cpp`.
- **Own-class using-declaration**: in a class with a dependent base it
  waits for instantiation (clang `isProvablyNotDerivedFrom`).
- **ADL** looks through `&f`, `(&f)` and `&(f)`. Test:
  `basic.lookup.argdep/address-of-overload-set-template.cpp`.
- **Base-specifier class-name** is a type-only lookup
  ([class.derived.general]/2). Test: `class.derived/base-lookup-ignores-namespace-qualified.cpp`.

## Classes, initialization, misc (cluster 16)

- A one-element braced list of the same (or a derived) class is that
  element's conversion for non-aggregates too (CWG1467, CWG2076). Test:
  `dcl.init.list/single-element-same-class-non-aggregate.cpp`.
- Redeclaration lookup in a class declares the implicit members it can find
  (`friend F &F::operator=(const F &);`). Test: `class.copy.assign/implicit-assign-befriended.cpp`.
- A mutable member is copied from a non-const lvalue, which may select a
  non-trivial template constructor or assignment. Test:
  `class.copy.assign/mutable-member-template-assign-not-trivial.cpp`.
- An explicit-object defaulted assignment (`S &operator=(this S &, const S
  &) = default;`) is a special member and is defined through its object
  parameter (`special_params` excludes the object parameter). Tests:
  `dcl.fct.def.default/explicit-object-{assign-traits,copy-assign-run}.cpp`.
- An assignment, prefix `++`/`--` or comma designating a bit-field promotes
  as the bit-field ([conv.prom]/5).
- `_BitInt(N)` operand types join the built-in arithmetic candidates.
- The implicit `namespace std` around an implicit `std::align_val_t` is
  hidden from ordinary lookup until the program opens `namespace std`.
- A member call's location in clang 22 mode is the member name's, so
  `__builtin_LINE()` in a default argument sees that line.

## Interface changes

`kiln_ast`: `ExprFlags::REFERENCE_PARAMETER`, `subst_nttp_expr_flagged`.
`kiln_sema`: `Sema::classify_base_class_name` (used by the parser for a
base-specifier), `special_params` (crate-internal).
