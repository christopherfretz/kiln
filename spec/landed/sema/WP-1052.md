# WP-1052 — dynamic exception-specification tails

Closes the exception-specification items WP-1017/WP-1078 left open.
Every case is matched against clang 19 (`-std=c++11`/`c++14`).

## Items

1. **Implicit special-member type lists.** Before C++17 an implicit
   destructor's specification is the union of its callees' dynamic lists
   (`implicit_dtor_exc`, excspec.rs). A redeclaration compares its
   written list with it as a set of adjusted types (`redecl_exc_equiv`,
   `check_special_redecl_exc`, except.rs). A destructor first declared
   without one stays implicit after its type is resolved
   (`implicit_exc_dtors`, clang `hasImplicitExceptionSpec`), which is
   where `-Wimplicit-exception-spec-mismatch` comes from. Tests:
   `except.spec/implicit-exception-spec-type-list{,-template}-cxx14.cpp`,
   `except.spec/implicit-exception-spec-redecl-cxx11.cpp`,
   `except.spec/dynamic-exception-spec-redecl-cxx14.cpp`.
2. **Listed types and dependent lists.** `check_specified_exception_type`
   (clang `CheckSpecifiedExceptionType`) rejects rvalue references and
   incomplete types (directly, through a pointer or a reference) and
   drops them. A dependent list is substituted when needed from C++11
   (DR1330; not in a local scope, DR1484) and each type is checked then,
   at the list's `)`. An overrider's dependent list is compared with the
   base's at definition time as well as per specialization (clang
   `CheckExceptionSpecSubset` has no dependent skip). Tests:
   `except.spec/dynamic-exception-spec-{incomplete,instantiation,member-instantiation,dependent-override}-cxx14.cpp`.
3. **Nested function types.** The positions WP-1102 did not cover
   already matched clang; no change.

## Follow-ups

- C++98: a function template specialization's list is not checked while
  deducing (`templ/subst/decls.rs`, `exc_spec`).
- C++17: a computed implicit list of "any type" and an overrider's
  dependent dynamic list are not compared.
- Types nested in a substituted function type
  (`templ/subst/types.rs`) are not checked.
