# WP-553 — out-of-line members whose types name the current instantiation through a partial specialization, an alias template or a nested class

Extends spec/sema.md §5.21 ("Current-instantiation template arguments in
an out-of-line return type") and spec/sema-templates.md §3.4. Clang 19
and 22 and GCC 16.1 agree on every case below.

## Equivalence of the in-class and out-of-line types ([temp.dep.type]/1, /6, [temp.over.link]/5)

- **Partial specialization with a non-type argument.** `vec<2, T>::`
  keeps its written argument `2` unconverted, so `current_instantiation`
  did not find the partial specialization `vec<2, T>` (registered with
  converted arguments) outside the declarator-id's own qualifier, and
  `typename vec<2, T>::length_type` stayed a `DependentName`:
  `T& vec<2, T>::operator[](typename vec<2, T>::length_type)` matched no
  declaration and `typename vec<2, T>::length_type vec<2, T>::size()`
  differed in its return type. `entered_partial_by_converted_args`
  (`templ/actions.rs`) now also applies inside (or in the declarator
  scope of) a class whose injected-class-name names the template, and
  `current_instantiation_at` (the current instantiation, else that
  conversion) is what `rebuild_ci_type` uses before the declarator-id.
- **Alias template specializations.** `rebuild_ci_type` (`decl.rs`)
  rebuilt the type arguments of a class template-id only; an alias
  template specialization (`std::remove_extent_t<typename B<T, C>::
  element_type>*`) is now formed again from its rebuilt arguments, so it
  substitutes to the in-class `std::remove_extent_t<element_type>*`.
- **Qualifier chains through member classes.** `typename policy::apply
  <HP>::type::owner` (an identifier component after the template-id)
  was left alone because only a template-id qualifier was resolved.
  `rebuild_ci_nns_record` resolves `X<P...>::` to the current
  instantiation and each following identifier to the member class it
  names, so a static data member, return or parameter type of a nested
  class of a member class template of a non-template class, of a class
  template or of a partial specialization is the in-class type.
- A qualifier that names another typedef, another partial specialization
  (`typename vec<3, T>::length_type` in a member of `vec<2, T>`), an
  alias template of another member or another nested class still makes
  the definition match nothing.

Tests: `tests/conformance/temp.dep.type/out-of-line-current-instantiation-*.cpp`
(partial-spec, alias, nested-member, run, neg, neg-clang22).
