# WP-1130 — member-template friend heads compare constraints

WP-1098 (in WP-1110) matched a [temp.friend]/5 member function template
friend (`template <class T> template <C U> friend int A<T>::f(U);`) against
the member template of each `A<X>` without its constraints, so a friend with
a type-constraint, requires-clause or trailing requires-clause the member
lacks (or the reverse) was befriended (accepts-invalid), and in an overload
set differing only by constraints both members were. The rule is in
spec/sema-templates.md §4.8 ("Constraints").

- `Sema::member_friend_constraints_match` (`kiln_sema/src/class/member_friend.rs`)
  compares the friend's type-constraints, head requires-clause and trailing
  requires-clause (`MemberFriend::requires`, new) with the member's
  ([temp.over.link]/6-7, [basic.scope.scope]/4): present at the same
  places, and equivalent ([temp.over.link]/5) once each side is substituted
  as clang's `AreConstraintExpressionsEqual` does. The friend's are
  substituted with its deduced arguments (and, for a friend instantiated with
  its class template, that instantiation's arguments, `MemberFriend::enclosing`,
  new), the member template's level retained; the member's (its pattern's)
  with its class's arguments (`Sema::member_cmp_constraints`, now
  `pub(crate)`). A non-template member's trailing requires-clause is compared
  the same way. A friend whose outer levels are not all known keeps the
  unconstrained comparison.
- The abbreviated friend `template <class T> friend int A<T>::i(C auto);`
  now has a member template head: the invented one
  (`Sema::open_invented_head_list`, templ/mod.rs). Before, it named no
  member at all.
- An instantiated friend's non-type template parameter types are
  substituted with the instantiation's arguments too (they used the friend's
  retained depth).
- clang 19 and 22 turn off access control for the befriending class
  (-Wunsupported-friend; clang 19 also rejects a constrained one with "friend
  declaration with a constraint that depends on an enclosing template
  parameter must be a definition", a clang 19 defect), so the tests are
  `skip(clang)`: `temp.friend/dependent-member-friend-constraints-denied.cpp`
  and `temp.friend/dependent-member-friend-constraints-overloads-run.cpp`.
