# WP-486 — `__is_trivially_relocatable` deprecation, `diagnose_if`, never-constant attribute conditions, explicit-object `enable_if`

The rules are in `spec/sema.md` "The `enable_if` attribute" and
"`diagnose_if`", and spec/sema-templates.md §9.1. In short:

- **`__is_trivially_relocatable`** warns `-Wdeprecated-builtins` ("builtin
  __is_trivially_relocatable is deprecated; use
  __builtin_is_cpp_trivially_relocatable instead") at clang 22 only,
  also once per instantiation. Tests:
  `tests/conformance/ext.traits/is-trivially-relocatable-deprecated.cpp`,
  `is-trivially-relocatable-deprecated-19.cpp`.
- **`enable_if` and explicit object parameters.** Overload resolution
  binds the call's arguments without the object argument from the
  object parameter on (clang's shifted binding); a direct call binds
  the object argument to the object parameter ([over.match.funcs.
  general]/4). A non-member operator's first operand binds to its first
  parameter ([over.match.oper]/2). A call that overload resolution chose
  is not checked again (`CallCallee::enable_if`, `OvlState::
  resolved_member`). Test: `tests/conformance/dcl.attr/enable-if-explicit-object.cpp`.
- **`diagnose_if`** (`diagnose_if.rs`): parsed with the parameters in
  scope; 3 or 4 arguments at clang 22, exactly 3 at clang 19. A condition
  naming a parameter or `this` is evaluated at each call with the
  converted arguments (`cond_with_args`, shared with `enable_if`); any
  other at each use of the function. The first true error alone, else
  every true warning (`-Wuser-defined-warnings`, shown in system
  headers), each with "from 'diagnose_if' attribute on 'f':" unless a
  group is given. Non-dependent calls in templates are rechecked per
  instantiation (`Sema::diagnose_if_recheck`). Explicit object member
  calls are rebuilt in templates through `rebuild_explicit_object_call`
  (they were "called object type … is not a function"). libc++'s
  `diagnose-if-support` feature is on. Tests:
  `tests/conformance/dcl.attr/diagnose-if.cpp`, `diagnose-if-form.cpp`,
  `diagnose-if-form-19.cpp`.
- **Never constant** (`attr_cond.rs`): an `enable_if`/`diagnose_if`
  condition that cannot be a constant expression for any parameter
  values is an error at the attribute, with the evaluation's notes, and
  the attribute is dropped; checked at the declaration and after
  substitution, where it is a hard error even during deduction. Test:
  `tests/conformance/dcl.attr/attr-cond-never-constant.cpp`.
