# WP-775 — llvm_project ADTTests and IRTests built by kiln: template fixes

Fixes found building llvm_project's ADTTests and IRTests entirely with
kiln (docs/status/oss/llvm_project.md, bug table). Each is pinned by a
run test compared with clang 19.

## Changes

- **The [temp.deduct.partial]/12 probe is a SFINAE context**
  (`kiln_sema/src/templ/order.rs` `undeduced_params_unused`). The check
  that a parameter left without a value is unused substitutes `int` for
  it; partial ordering runs on every pair of viable templates, so a
  qualifier the probe cannot form (`typename O::pointer` with `O = int`)
  must fail the probe quietly, never as a hard error ([temp.deduct.general]/8).
  Test: `tests/conformance/temp.func.order/p12-undeduced-probe-is-sfinae-run.cpp`.
- **`T(args)` with a non-dependent `T` is not type-dependent**
  ([temp.dep.expr]/3; `kiln_ast/src/templates.rs` `unresolved_construct`).
  A type-dependent argument makes the expression value- and
  instantiation-dependent only (clang `computeDependence` for
  `CXXUnresolvedConstructExpr`), so direct-initialization from it is
  checked as direct-initialization (an `explicit` constructor stays
  viable) and overload resolution sees its type.
  Test: `tests/conformance/temp.dep.expr/functional-cast-not-type-dependent-run.cpp`.
- **Explicit specialization of a member class named through a typedef**
  ([temp.expl.spec]/1, /16; `kiln_parse/src/templ.rs`
  `at_spec_member_tag_decl`). `template<> class P::R {}` whose qualifier
  is a typedef or alias of a class template specialization is parsed as
  the `X<int>::R` spelling is, not routed to the unimplemented fallback.
  Test: `tests/conformance/temp.expl.spec/member-class-via-typedef-run.cpp`.
- **Printing a specialization's name instantiates nothing**
  ([temp.inst]/2, [temp.expl.spec]/7; `kiln_sema/src/templ/class.rs`
  `default_shape_matches`). Whether a written argument equals its
  default (clang `isSubstitutedType`) compares a specialization's
  arguments structurally before the default is substituted, so a written
  `Set<N*>` against `Set<typename GT<G>::NodeRef>` does not instantiate
  `GT<N*>` ahead of its explicit specialization.
  Test: `tests/conformance/temp.expl.spec/after-template-id-with-written-defaults-run.cpp`.
- **A type qualifier naming a dependent name is canonically that name**
  ([temp.dep.type]/1, [dcl.typedef]/2; `kiln_ast/src/types/nns.rs`
  `TypeContext::nns`). `RegionT::` with `using RegionT = typename
  Tr::RegionT` has the canonical nested-name-specifier of
  `Tr::RegionT::` (clang `getCanonicalNestedNameSpecifier`), so an
  out-of-line member definition may spell its type either way.
  Test: `tests/conformance/temp.dep.type/qualifier-through-member-alias-run.cpp`.
- **A default argument instantiates what its conversion names only when
  a call uses it** ([dcl.fct.default]/5, [temp.inst]/5,
  [basic.def.odr]/8; `kiln_sema/src/templ/class.rs`
  `defer_default_arg_uses`, `queue_default_arg_uses`). While a default
  argument is converted outside any other function body, the member
  definitions it would queue for instantiation (a constructor, the
  temporary's destructor) are recorded with the stored argument
  (`InstState::deferred_default_uses`) and queued where a call uses it
  (`note_default_use`), as clang's `PotentiallyEvaluatedIfUsed` context
  and `CheckCXXDefaultArgExpr` do. A constexpr function is still
  instantiated at once (§4.11). An unused `P<Incomplete> p = nullptr`
  no longer instantiates `~P<Incomplete>`.
  Test: `tests/conformance/dcl.fct.default/conversion-instantiates-only-when-used-run.cpp`.
- **A qualified member set with a static member, through an implicit
  `this` of an unrelated class, is not an error**
  ([class.mfct.non.static]/2, [expr.prim.id.general]/3;
  `kiln_sema/src/class/member_expr.rs` `member_access`). `F::isT(i)` in
  a member of a class template with a dependent base is kept as
  `this->F::isT` until instantiation; if `F` is then not a base and the
  set has a static member, it is the qualified overload set without an
  object (clang `CheckQualifiedMemberReference`), and a non-static
  winner is diagnosed by the call.
  Test: `tests/conformance/class.mfct.non.static/qualified-static-through-dependent-base-run.cpp`.
- **An overloaded member access is an overload set for deduction**
  ([temp.deduct.call]/6, [over.over]/3; `kiln_sema/src/templ/deduce_call.rs`
  `overload_set_arg`, `resolve_overload_for_deduction`). The argument
  `o.f<K>` contributes the types of its static members; a template-id
  naming one specialization gives its type for any `P` (clang
  `ResolveSingleFunctionTemplateSpecialization`). Converting it to a
  function pointer names the static specialization without "cannot
  create a non-constant pointer to member function", which stays for a
  non-template-id (`kiln_sema/src/overload/address.rs`
  `resolve_member_address`).
  Test: `tests/conformance/temp.deduct.call/member-access-template-id-argument-run.cpp`.
- **A constant arm of an lvalue conditional is its value** ([basic.def.odr]/5,
  [expr.cond]/4; `kiln_codegen/src/expr.rs` `emit_scalar_opt`,
  `non_odr_use_constant`). In `c ? A : B` with `static const` integral
  members, each arm reached by the scalar visitor is emitted as the
  constant, not as a load of an `available_externally` global; an
  internal-linkage class (MemorySanitizer.cpp) otherwise failed to link.
  Test: `tests/conformance/basic.def.odr/conditional-arms-constant-not-odr-used-run.cpp`.
