# WP-771 — finish P2841R7 (and P2963R3 subsumption)

Closes the WP-746 remainder (BACKLOG WP-758): P2841R7 is `done` in
docs/STANDARD_SUPPORT.md and `__cpp_template_parameters` is defined.

## Changes

- **Nested TTP kinds** ([temp.arg.template]/3, [temp.param]/1;
  spec/sema-templates.md §2.1.1). P0522 matching compares the kinds of
  template template parameters nested in a TTP's head
  (`templ/ttarg22.rs` `ttp22_arg_fits`), with clang 22's "does not refer
  to a ..." error and notes. Redeclarations already compared them.
- **Atomic-constraint mappings** ([temp.constr.atomic]/1; §8.2). An
  atom's parameter mapping keeps only the parameters its expression
  names (`templ/concepts/used.rs`, a whitelist walk; unknown nodes keep
  the whole mapping), so `C<T, int>` and `C<T, long>` share
  `sizeof(T) > 1`, and atoms of a concept-pack fold's init or pattern are
  shared across expansions.
- **Fold expanded constraints** ([temp.constr.fold], P2963R3; §8.2, §8.4).
  `NormNode::Fold { and, pattern, packs }` for `&&`/`||` folds over type
  and non-type packs (also through a concept's mapping); subsumption
  compares folds by operator, pack set and pattern (`leaf_subsumes`,
  `subsumes_positional`).
- **Unexpanded packs** ([temp.variadic]/12). A requires-clause and a
  concept's constraint-expression naming an unexpanded pack (type,
  non-type or concept template parameter pack) are "expression contains
  unexpanded parameter pack" (`act_on_requires_clause`, `act_concept`).
- **Concept heads** ([temp.param]/14). A pack before a concept's last
  template parameter is an error, as in clang 22.
- **Macro** ([cpp.predefined]). `__cpp_template_parameters` 202502L at
  C++26 with `-fclang-compat=22` (`kiln_pp` `kiln_features`).
