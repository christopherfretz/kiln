# WP-1111 — rewritten comparison candidates against non-rewritten ones

Found by WP-1008: in fmt 12.1.0's chrono test, kiln defined libstdc++'s
`std::chrono::leap_second` `operator<=>(const leap_second&, const
sys_time<D>&)` where clang defines `operator<(const sys_time<D>&, const
leap_second&)` and `operator>=` (the comparisons `__ss < __pos[-1]` and
`(__ss + 1s) >= __pos[-1]` in `__get_leap_second_info`, and
`std::upper_bound` over the leap seconds). Kiln ran a different function
than clang. Spec: spec/sema-overload.md §4.1 items 5-6, §5.1.

- **Templates: [temp.func.order]/6.2.1 is not applied** (`templ/order.rs`
  `constraints_comparable`).
  - Root cause: for a reversed candidate, kiln reversed the parameters
    before the /6.2.2 "positionally corresponding parameters have the
    same type" check, as the standard says. Clang ("Match GCC on not
    implementing [temp.func.order]p6.2.1") and GCC compare them as
    declared. `operator<(sys_time<D>, leap_second)` against the reversed
    `operator<=>(leap_second, sys_time<D>)` therefore compared
    constraints in kiln, and the `three_way_comparable_with<seconds>`
    parameter made `<=>` more specialized (/2.5) before the /2.8
    non-rewritten tie-break could pick `operator<`.
  - Fix: the /6.2.2 check ignores the reversal. Deduction
    ([temp.func.order]/3) still reverses. A pair whose declared lists
    match positionally (`(const X&, const Y&)` both) compares constraints
    even when one is reversed, as clang 19/22 and GCC do.
- **Non-templates: /2.6 after reversal** (`overload/best.rs`
  `order_constrained_candidates`, `same_param_type_lists`).
  - Root cause: the same-parameter-type-lists check for the
    more-constrained rule ignored reversal, so a constrained hidden
    friend `operator<=>(const W&, const T&)` used reversed for `t < w`
    lost to `operator<(const T&, const W&)` by /2.8, and a reversed
    `operator==(const W&, const T&)` with stronger constraints lost to
    `operator==(const T&, const W&)`.
  - Fix: when exactly one of the two candidates is reversed, its list is
    compared reversed (clang `sameFunctionParameterTypeLists`).
- **Checked, already right:** the order of /2.1 (ICS, a reversed
  candidate in parameter order), /2.4, /2.5, /2.8 and /2.9; ambiguity
  between a rewritten and a non-rewritten candidate; P2468 `==`/`!=`
  suppression (member and namespace `!=`, other namespace, other
  parameter types, templates, `!=` rewritten, hidden friends). All match
  clang 19 and 22.
- **Effect:** fmt 12.1.0 `test/chrono-test.cc` (`-std=gnu++20 -O0
  -emit-llvm`): the set of defined functions is now the same as clang
  19's (5899 names, previously the `leap_second` operators differed).
- Tests in `over.match.best/`: `rewritten-leap-second-run.cpp` (the
  reduced libstdc++ shape), `rewritten-reversed-constraints-run.cpp`
  (template and non-template, `<`, `>=`, `==`, `!=`),
  `rewritten-tiebreak-order-run.cpp` (/2.1, /2.4, /2.5, reversed ICS,
  /2.8, /2.9), `rewritten-ambiguous.cpp` (strict diags); in
  `over.match.oper/`: `p2468-eq-ne-suppression.cpp` (strict diags). Each
  passes under kiln, clang 19 and clang 22.
