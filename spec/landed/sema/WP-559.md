# WP-559 — block-scope using of a literal operator

Extends spec/sema.md (using-declarators: block scope, operator and
literal-operator names). clang 19/22 and GCC 16.1 accept every accepted
case below.

## Rule ([namespace.udecl]/1, [lex.ext]/5, [over.match.oper]/3.2)

- A using-declarator at block scope may name a literal operator
  (`using udl::operator""_t;`) or a non-member operator function
  (`using ops::operator+;`). kiln reported `an operator name in a
  block-scope using-declarator is not supported yet`, and every later
  `"x"_t` then failed lookup.
- The shadows now go to `Scope.local_names` (`(DeclName, DeclId)`,
  `crates/kiln_sema/src/scope.rs`; `Sema::push_local_name`), which
  `lookup_name_scoped` consults for non-identifier names at each block
  scope and `current_scope_raw_dn` returns for redeclaration checks. So
  the name is found from the declarator to the end of the block, hides
  outer declarations, and several declarators of one name overload.
- In a function template a non-dependent declarator is redone by the
  instantiation (`local_using_decl` now looks the full `DeclName` up).
- A literal-operator name with a class, enumeration or dependent
  qualifier reports clang's `non-namespace scope 'C::' cannot have a
  literal operator member` at every scope (new id
  `sema_literal_operator_id_outside_namespace`); a dependent qualifier
  with an operator name at block scope stays "not supported yet".

## Tests

- `tests/conformance/namespace.udecl/block-scope-using-literal-operator.cpp`
  (run): a hash switch with `"x"_t` case labels, two suffixes from two
  namespaces, two declarators of one suffix, an inner block hiding a
  namespace-scope declaration, constant evaluation, a function template.
- `…/block-scope-using-literal-operator-scope.cpp` (strict-diags): a use
  before the declarator and after its block fail.
- `…/block-scope-using-operator.cpp` (run): operator expressions and
  `operator-(…)` calls find block-scope `using ops::operator…;`, hiding
  a global operator; a function template's dependent operands.
- `…/literal-operator-class-qualifier.cpp` (strict-diags): class and
  dependent qualifiers at namespace, class and block scope.
