# WP-1075 — break/continue in a statement expression in a loop header

kiln rejected `for (; ({ break; 1; });) {}` and similar valid code (found by WP-971): sema's breakable stack was pushed only when the loop body started, so a jump in a loop's condition or increment saw no enclosing loop. The rules now match clang 19 and 22 (spec/sema.md §7.4a).

- **Sema** (`kiln_sema/src/stmt.rs`, `kiln_parse/src/stmt.rs`, `templ/subst/stmts.rs`).
  - The loop is open from its condition (`while`, `for` after the init) or body (`do`, range-based `for`) to the end of the statement; a `do` stays open through its condition. A `switch`, a `for` init-statement and a range-based `for`'s init and range belong to the enclosing statement.
  - New error `sema_continue_from_cond_var_init`: a `continue` targeting the `for` loop whose condition variable it initializes (clang's `err_continue_from_cond_var_init`). A `while` condition variable's `continue` stays valid.
  - Lambdas still stop the search; a template definition diagnoses at definition time.
- **Codegen**: no change. `kiln_codegen/src/stmt.rs` already pushed its jump targets at clang's points; run output and `-O0` IR match clang 19 and 22.
- **CFG** (`kiln_sema/src/cfg/build.rs`): header jumps follow clang's analysis graph (outer loop for `while`/`do` conditions and `for` `continue`, loop exit for `for` and range-for `break`, switch exit for a switch header `break`); a jump with no target makes the CFG bad (`Status::NoCfg`), which silences CFG warnings as in clang.
- **Oven** (`kiln_oven/src/compile.rs`): the statement-expression check runs before the "outside a loop" trap, so a header jump gets clang's "this use of statement expressions is not supported in a constant expression" at the right statement.
- **Oracle disagreement**: GCC rejects all of these jumps; kiln follows clang.
- Tests:
  - `stmt.break/stmt-expr-loop-header-run.cpp` (while, do, for condition/increment/init, nested inner headers, switch condition, range-for range, condition variables; also the constexpr functions run at run time);
  - `stmt.cont/stmt-expr-loop-header-errors.cpp` (no enclosing loop, lambda, for condition variable, template; valid twins);
  - `stmt.break/stmt-expr-loop-header-cfg.cpp` (-Wreturn-type/-Wuninitialized/-Wunused parity, badCFG);
  - `ext.gnu.stmt.expr/constexpr-loop-header-jump.cpp` (constant-evaluation notes);
  - `stmt.while/ir-stmt-expr-loop-header-jump.cpp` (IR vs the oracle).
- Follow-ups: expansion-statement headers; dropping an erroneous jump like clang's `StmtError` (missing "no case matching constant switch condition" after one).
