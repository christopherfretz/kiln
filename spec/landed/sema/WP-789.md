# WP-789 — coroutine libraries built by kiln: template, access and codegen fixes

Fixes found building stdexec, libunifex and folly::coro with kiln
through their own CMake builds and test suites
(docs/status/oss/{stdexec,libunifex,folly_coro}.md). Each is pinned by a
conformance test checked under kiln and clang 19 (paths below are under
`tests/conformance/`). The spec sentences are in spec/sema-templates.md,
spec/sema-class.md and spec/codegen.md.

## Templates and deduction

- **A friend's deduced return type comes from another redeclaration's
  definition** (`kiln_sema/src/deduce.rs`): a friend declared without a
  body in one specialization and defined in another is one function.
  `temp.friend/deduced-friend-defined-by-other-specialization.cpp`.
- **Partial specializations over an `auto` non-type parameter**
  (`templ/spec.rs`, `templ/deduce.rs`; [temp.over.link]/6,
  [temp.deduct.type]/20). `temp.spec.partial.general/auto-primary-*.cpp`.
- **A friend template's signature is substituted with its class's
  access** ([class.friend]/7; `templ/funcs.rs`
  `friend_template_access_ctx`).
  `class.friend/friend-template-signature-private-access-run.cpp`.
- **A typed declarator names no deduction guide** (`kiln_parse`
  `class.rs`, `decl.rs`).
  `temp.deduct.guide/typed-function-named-like-class-template-run.cpp`.
- **A constrained friend naming a member class of the enclosing
  template is a template of its own per specialization** ([temp.friend]/9;
  `templ/subst/types.rs`).
  `temp.friend/constrained-friend-of-member-class-of-template-run.cpp`.
- **A name not found in a current instantiation with a dependent base
  is dependent** ([temp.dep.type]/6; `decl.rs`).
  `temp.dep.type/current-instantiation-qualifier-unknown-member-alias-run.cpp`.
- **A template template pack expansion is checked by its pattern**
  ([temp.variadic]/5; `templ/args.rs`).
  `temp.variadic/template-template-pack-expansion-partial-spec-run.cpp`.
- **An injected-class-name is a concept's template template argument**
  ([temp.local]/1; `templ/actions.rs`).
  `temp.local/injected-class-name-concept-template-template-arg-run.cpp`.
- **A member function being instantiated is not instantiated again**
  (`templ/class.rs`). `temp.inst/constexpr-members-mutually-recursive-run.cpp`.
- **A constructor's instantiated noexcept-specifier has `this`**
  ([expr.prim.this]/3; `except.rs`).
  `except.spec/ctor-noexcept-implicit-this-member-run.cpp`.
- **A local class's member body sets aside the enclosing function's
  pending references** (`templ/subst/local.rs`).
  `class.local/member-body-after-tuple-binding-run.cpp`.
- **A return-type-requirement's type-constraint expands its pack
  expansions** (`templ/concepts/requires.rs`).
  `expr.prim.req.general/compound-type-constraint-pack-expansion.cpp`.
- **A base class is deduced from the deductions made before its derived
  class was tried** ([temp.deduct.call]/5; `templ/deduce.rs`).
  `temp.deduct.call/base-after-template-template-mismatch-run.cpp`.
- **An explicit class-type template argument matches only a base with
  the same template parameter object** (`templ/deduce.rs`).
  `temp.deduct.call/explicit-class-nttp-selects-base-run.cpp`.
- **A class member access names a static data member template's
  specialization** (`class/member_expr.rs`, `kiln_parse/src/expr.rs`).
  `temp.names/member-access-variable-template*.cpp`.
- **An in-class explicit specialization of a member variable template**
  is redeclared with its class and emitted on odr-use ([temp.expl.spec]/3,
  CWG 727). `temp.expl.spec/in-class-member-variable-template-spec-run.cpp`.
- **A conversion function's undeduced return type is deduced before it
  is a candidate** (`overload/ics.rs`).
  `class.conv.fct/operator-auto-of-class-template-candidate-run.cpp`.
- **A member function template overrides no virtual function**
  ([temp.mem]/4; `class/virtual/mod.rs`).
  `temp.mem/member-template-does-not-override-run.cpp`.
- **A local class member does not end a generic lambda's invented
  head** (`ClassBuild::heads`, `act_on_end_abbreviated`).
  `class.local/generic-lambda-local-class-member-then-local-run.cpp`.

- **A `template` keyword after a member access's nested-name-specifier
  belongs to that qualifier** (CWG1835; `kiln_parse/src/expr.rs`):
  `e.template B<T>::m` names `m` of base `B<T>`, not a template `m`.
  `temp.names/template-kw-before-member-qualifier-run.cpp`.
- **A failed `static_assert` prints its concept-id requirement**
  (`kiln_ast/src/dump/names.rs`; the substituted concept-id keeps its
  written qualifier, `templ/concepts/sat.rs`).
  `dcl.pre/static-assert-concept-id-requirement.cpp`.
- **A placeholder's type-constraint is completed with the concept's
  default template arguments** ([temp.arg.general]/9;
  `templ/auto.rs` `check_placeholder_constraint`).
  `dcl.spec.auto/type-constraint-uses-concept-default-args.cpp`.

## Access and attributes

- **An implicit special member defined during alias substitution checks
  access from itself** (`class/special/define.rs` `push_synth` sets
  `access_ctx` aside): a protected base destructor of a `noexcept`
  operand's temporary is accessible.
  `temp.alias/implicit-dtor-defined-in-alias-checks-access-from-itself.cpp`.
- **GNU `artificial`** is accepted on an inline function and warned
  elsewhere, as clang does (`decl_attrs.rs`). `dcl.attr/gnu-artificial.cpp`.

## Codegen

- **A glvalue `co_await` used as a prvalue loads its referee**
  (`kiln_codegen/src/expr.rs`).
  `expr.await/reference-result-loaded-by-value-run.cpp`.
- **A default member initializer's `this` is the aggregate being
  initialized** (`FnState::default_init_this`, `enter_default_init`;
  clang's `FieldConstructionScope`). Before, an NSDMI evaluated in an
  aggregate initialization (`T{}` inside a member function) used the
  enclosing function's `this`.
  `dcl.init.aggr/default-member-init-this-is-the-aggregate-run.cpp`.
