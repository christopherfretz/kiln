# WP-726 — folly through its own build and tests (M8 wave 3)

folly v2026.10.26.00 built with kiln++ through its own CMake build with
its tests enabled (docs/status/oss/folly.md). Each fixed behaviour below
is a kiln bug the build found, reduced to a standalone test; the rule is
stated in the spec named.

## Changes

- **`-finput-charset=` / `-fexec-charset=`** (spec/driver.md). `UTF-8`
  in any letter case is accepted, any other value is clang's "invalid
  value". kiln++ rejected both flags as unknown, which failed every TU.
  Test: `kiln_driver/tests/driver.rs`.
- **A declarator qualifier's template arguments are not entered**
  (spec/sema-templates.md). In `template<class T> int F<T, typename
  X<T>::type>::g()` the argument `X<T>` is not the current instantiation
  of `X` (fmt 10's `formatter<T, Char, enable_if_t<...>>::format`).
  Test: `temp.spec.partial.member/out-of-line-member-dependent-name-arg.cpp`.
- **`__builtin_memcpy_inline`, `__builtin_assume_separate_storage`,
  `__builtin_unpredictable`** (spec/sema.md, spec/codegen.md; private
  ids 2176-2178). Lowered as clang 19: `llvm.memcpy.inline`,
  `llvm.assume(i1 true)` with a `"separate_storage"` bundle, the operand.
  None is a constant expression.
  Tests: `ext.gnu.builtins/memcpy-inline-{args,run}.cpp`,
  `ext.gnu.builtins/unpredictable.cpp`, `tests/codegen/builtin_memcpy_inline.cpp`.
- **`.*` instantiates the left operand's class** before the base check
  ([expr.mptr.oper]/2-3, [temp.inst]/2; spec/sema-class.md).
  Tests: `expr.mptr.oper/lhs-{incomplete,instantiates-derived}.cpp`.
- **`Q::m` converts the object through its `Q` subobject**
  ([class.member.lookup]/8; spec/sema-class.md), for fields and calls.
  Tests: `class.member.lookup/p8-qualifier-selects-subobject.cpp`,
  `tests/codegen/qualified_member_subobject.cpp`.
- **Injected-class-names of one template in several bases**
  ([temp.local]/4; spec/parse.md): as a template-name not ambiguous.
  Test: `temp.local/p4-injected-names-same-template.cpp`.
- **constexpr defaulted special members used by a constant initializer
  in a template definition are defined** (spec/sema-class.md; clang
  `NeededForConstantEvaluation`).
  Test: `dcl.constexpr/defaulted-special-in-template.cpp`. Such a
  definition runs outside the template's context, so the subobject
  members it uses are odr-used and emitted (otherwise every function
  template declaring a `std::vector` local left `_Vector_impl()` and
  `~allocator()` undefined at link). Test:
  `dcl.constexpr/defaulted-special-in-template-odr-uses-members.cpp`.
- **Instantiated static member definitions keep `constinit`**
  (spec/sema-templates.md).
  Test: `dcl.constinit/static-member-template-definition.cpp`.
- **`using T::C` names the constructors when `C` is `T`'s
  injected-class-name** through a typedef qualifier ([class.qual]/2;
  spec/sema-class.md). Same rule as WP-724's `using.rs` change.
  Test: `namespace.udecl/inheriting-via-typedef-qualifier.cpp`.
- **No current-instantiation conversion for a pack expansion into a
  non-pack parameter** (spec/sema-templates.md; googletest
  `Templates<Tail_...>`).
  Test: `temp.variadic/template-template-expansion-own-template.cpp`.
- **An overload set converts to a class through a converting
  constructor** ([over.over]/1; spec/sema-overload.md).
  Tests: `over.over/class-target-{converting-ctor,no-constructor}.cpp`.
- **A mixed static/instance member call captures `this` only for an
  instance winner** ([expr.prim.lambda.capture]/8; spec/sema-lambda.md).
  Tests: `expr.prim.lambda.capture/implicit-this-{instance,static}-overload-winner.cpp`.
- **A conversion function named by a using-declaration is found as its
  shadow**, with the using-declaration's access ([namespace.udecl]/19;
  spec/sema-overload.md).
  Tests: `namespace.udecl/conversion-function-via-using{,-access}.cpp`.
- **Partial ordering deduces an A pack expansion as a whole**
  ([temp.deduct.type]/9; spec/sema-templates.md §6.7).
  Test: `temp.func.order/p3-pack-expansion-other-index.cpp`.
- **Partial ordering fails a deduction that leaves a used parameter
  without a value** ([temp.deduct.partial]/12; §6.7 step 4).
  Test: `temp.func.order/p12-undeduced-used-in-non-deduced-context.cpp`.
- **An out-of-line member of a partial specialization with pack
  arguments finds it** ([temp.spec.partial.member]/1).
  Test: `temp.spec.partial.member/out-of-line-member-pack-arguments.cpp`.
- **A not-yet-defined member class of the current instantiation is a
  dependent qualifier** ([temp.dep.type]; spec/sema-templates.md).
  Tests: `temp.dep.type/incomplete-member-class-qualifier{,-missing}.cpp`.
- **`&C::m` as a template argument while `C` is being defined** is the
  member itself, without evaluating it ([temp.arg.nontype];
  spec/sema-templates.md).
  Test: `temp.arg.nontype/member-pointer-of-class-being-defined.cpp`.
- **A friend template constrained on an enclosing template's parameters
  is its own template** in each specialization ([temp.friend]/9;
  spec/sema-templates.md; `Sema::friend_template_apart`).
  Test: `temp.friend/p9-constraint-on-enclosing-distinct.cpp`.
- **Miscompile: a reference bound to a `co_await` with a reference
  result** reloads its bound address across the full-expression's
  cleanups that the suspension's destroy path shares (spec/codegen.md
  coroutines; clang `EmitExprWithCleanupsLValue`). kiln emitted IR that
  failed verification ("Instruction does not dominate all uses").
  Test: `expr.await/reference-result-bound-to-reference.cpp`.
- **[dcl.constexpr]/3 (C++20)**: an if-statement's init-statement and
  condition variable are not checked by the non-literal-variable rule,
  as in clang 19 (spec/sema.md, `first_non_literal_var`); a loop's and
  a switch's still are. Test:
  `dcl.constexpr/p3-if-condition-variable-not-checked.cpp`.
- **Lookahead through an explicit specialization's member typedef**:
  `X<A>::m::name` with `m` a typedef of `X`'s primary pattern and an
  explicit specialization `X<A>` is parsed ahead for real (spec/parse.md
  `annotate_template_scope`), so `v<traits<clk>::spec::fine_clock>` is a
  type-id, not "does not refer to a value". Test:
  `temp.expl.spec/member-typedef-through-specialization-in-template-arg.cpp`.
- **Variable templates declared `auto&` / `const auto*`** deduce their
  type from the instantiated initializer like a plain `auto` (spec
  sema-templates.md §4.11, `get_var_spec`); a use in another constexpr
  initializer was "depends on itself". Test:
  `dcl.spec.auto/variable-template-reference-placeholder.cpp`.
- **A pure member of a dependent class** (`void w(int) override = 0;`
  over a dependent base) is checked at instantiation, not at the
  definition (spec/sema-class.md Pure/abstract, clang `CheckPureMethod`).
  Tests: `class.abstract/pure-override-of-dependent-base.cpp`,
  `pure-not-virtual-at-instantiation.cpp`.
- **Codegen: a vector subscript of a reference-returning call**
  (`get(p)[1]`, `v[i][j]` on `std::vector<V>`) loads the vector from the
  returned address (spec/codegen.md §7w); IR lowering failed
  ("extractelement on a non-vector"). Test:
  `ext.vector/subscript-of-reference-returning-call-run.cpp`.
- **A pseudo-destructor on a vector type** (`v.~V()`) is accepted as on a
  scalar (clang `BuildPseudoDestructorExpr`), so libstdc++'s
  `is_destructible<V>` holds and `std::vector<uint64x2_t>` compiles
  (spec/sema-class.md). Test:
  `expr.prim.id.dtor/pseudo-destructor-vector-type-run.cpp`.
- **A parenthesized function-template name suppresses ADL**
  ([basic.lookup.argdep]/1): `(f)(t)` built an ADL `UnresolvedLookupExpr`,
  so instantiation found an associated namespace's `f` too ("call to
  'iterator_arrow_result' is ambiguous" in boost's reverse_iterator;
  spec/sema-overload.md §2.2). Test:
  `basic.lookup.argdep/parenthesized-function-template-no-adl.cpp`.
- **`__atomic_is_lock_free` with an integer cast to a pointer** folds
  when the integer is a multiple of the size (spec/oven.md Atomics, clang
  19 `toIntegralConstant`), so `std::atomic<T>::is_lock_free` needs no
  libatomic (folly's atomic_struct and relaxed_atomic tests did not
  link). Test: `ext.c11.atomic/is-lock-free-integer-pointer-run.cpp`.
- **Miscompile: `decltype` of a builtin call in a signature.** A
  builtin first used inside a template was declared with `DEPENDENT_CTX`,
  so every reference to it stayed instantiation-dependent and the
  specialization of `auto f(A... a) -> decltype(__builtin_operator_new(a...))`
  kept a dependent return type, lowered as `i8`: folly's `operator_new`
  returned a truncated pointer and `atomic_grow_array` (thread locals,
  hazptr, futures, fbstring: ~790 tests) crashed. The builtin is now
  declared outside any template scope (spec/sema.md §5.3), and the call's
  callee mangles as `L_Z <name> E` (spec/abi.md). Test:
  `dcl.type.decltype/builtin-call-return-type-run.cpp`.
- **oss harness** (spec/landed/harness/WP-666.md): `@OSS@` in a
  project's `configure` names `scripts/oss`; the folly row and its
  liburing shim.
