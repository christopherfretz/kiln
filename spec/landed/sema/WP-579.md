# WP-579 — overloads distinguished only by enable_if

Extends spec/sema-overload.md §4.3 (new) and spec/sema.md §4 (`enable_if`).

Abseil's `SpinLock` declares `constexpr explicit SpinLock(SchedulingMode)` twice,
the second `[[deprecated]]` and `__attribute__((enable_if(mode ==
SCHEDULE_COOPERATIVE_AND_KERNEL, "...")))`. Clang treats the two as overloads
(`Sema::IsOverload` compares the condition lists); kiln rejected the second as
"constructor cannot be redeclared".

- Identity: `act_on_special_declarator` (crates/kiln_sema/src/class/special/declare.rs)
  now requires equal `enable_if` lists before treating a constructor as a
  redeclaration, as `fn_corresponds` already did for other functions. Instantiated
  members of a class template take the pattern's conditions through
  `Sema::inst_enable_if` (set in `Substituter::function_decl`,
  crates/kiln_sema/src/templ/subst/decls.rs), because the instantiation's
  attributes are copied only after it is declared; `Sema::new_fn_enable_if`
  (crates/kiln_sema/src/enable_if.rs) reads it.
- Mangling: `enable_if_conds` (crates/kiln_abi/src/mangle.rs) emits
  `Ua9enable_ifI <template-arg>* E` between the name and the bare function type
  (clang `mangleFunctionEncodingBareType`). An enumerator in a template-argument
  expression mangles as its literal `L <enum-type> <value> E` and is primary
  (crates/kiln_abi/src/mangle/dep.rs). Before, overloads collided as "definition
  with same mangled name".
- Deprecation of constructors: kiln never warned on a deprecated constructor.
  `use_ctor` (crates/kiln_sema/src/class/special/define.rs) now calls
  `Sema::warn_deprecated_use` (split out of `diagnose_deprecated`,
  crates/kiln_sema/src/deprecated.rs) at the clang location: the variable for
  direct-initialization, the initializer for class copy-initialization, the
  converted expression for a converting constructor of a UDC (`CtorCall::udc`,
  set by `construct_class` for `InitStyle::Copy`).

Tests: tests/conformance/dcl.attr.enable_if/ (ctor-overload, free-fn-overload,
member-fn-overload, template-overload, identical-redefinition, ambiguous,
deprecated-selected), tests/conformance/dcl.attr.deprecated/ctor-use.cpp, and
tests/mangle/enable_if.cpp in the mangling differential; all clang 19-checked.
