# WP-556 — `-Wuninitialized` mem-initializer walk through a glvalue conditional operator

Extends spec/sema-class.md (constructor mem-initializers, warnings).

`uninit_value` (crates/kiln_sema/src/class/ctorinit.rs) read a `ConditionalOperator`
node with the binary-operand accessor (`operands`), which asserts on that kind, so any
constructor whose mem-initializer applied an lvalue-to-rvalue conversion to a glvalue
`?:` (`b(k ? a : d)`) aborted the compiler. The condition is `operand(e)` and the arms
are `cond_arms(e)`; the walk now visits the condition as a use and both arms as value
uses, as before for the non-aborting shapes. Diagnostics match clang 19:
`tests/conformance/class.base.init/uninitialized-conditional.cpp`.
