# WP-658 — Friend redeclaration index: same-signature candidates only

This WP adds the "Redeclaration index" paragraph to spec/sema.md §3
(Lookup). The measurements, counts and A/B tables are in
docs/status/perf-reflection.md, in the section "WP-658: friend
redeclaration index" (follow-up row F14).

Nothing observable changes. The following stay byte-identical: the
previous declaration a function declaration redeclares, the invalid and
other-kind outcomes of `pick_prev_function` (the newest corresponding
valid candidate wins; the first invalid one is remembered), the
using-declarator checks (`shadows`, `friend_befriends_using_target`),
the dependent-friend filter, every diagnostic and note and their order,
the AST dump and the emitted IR.

## Changes

- **Redeclaration index** (`kiln_sema/src/overload/redecl_index.rs`,
  `Sema::redecl_candidates`).
  - Used by the unqualified-friend arm of `act_on_function_declarator`
    (`hidden_friend_redecl_set`) and by `pattern_friend_prev` (friends
    instantiated from a class template's pattern).
  - A lookup entry that is an overload set of 32 or more declarations is
    indexed; shorter ones, a non-prototype new type and
    `full_redecl_scan` take the full list as before.
  - Each position is keyed by a hash of its parameter-type list
    (function or function template, variadic, canonical parameter
    types; for a function template, its latest pattern's type). Entries
    the hash cannot judge get the key every query returns: non-function
    entities, using-shadows, unresolved using-declarators, templates
    other than function templates, declarations without a type and
    declarations with a non-prototype (error) type.
  - A query returns, in lookup order, the positions keyed like the new
    declaration plus the always-returned ones. Every position left out
    is one `fn_corresponds` rejects on its parameter list before any
    side effect, or one `pick_prev_function` skips (a template for a
    non-template declaration or the reverse). `INVALID` and the lookup
    flags are read live, never keyed.
- **Journals** (`kiln_ast/src/journal.rs`).
  - `LookupTables::journal` records a slot replaced in place and a set
    that shrank; `DeclArena::ty_journal` records `set_ty`;
    `RedeclTable::journal` records the old latest declaration of a
    group whose latest moves.
  - They are off until the first indexed query. Each query drains them
    and re-keys the positions that read a journaled declaration; a set
    that shrank, or a journal past 65,536 events, drops the index, which
    is rebuilt lazily.
- **Template heads.** The key holds no head: two function templates
  with equal parameter lists and different heads share a key, and
  `fn_corresponds` (`heads_equivalent`, return types, requires-clauses,
  `enable_if`) still tells them apart.
- **Counters** (`op-stats`, `templ/deduce_stats.rs`): per call site of
  `pick_prev_function`, candidates scanned, `fn_corresponds` calls,
  correspondences, hits and their position from the end; the index's
  queries, entries returned, keyed positions and heap bytes.

## Test-only entry

`Sema::full_redecl_scan` (`#[doc(hidden)]`, also
`ParseOptions::full_redecl_scan`) turns the index off.
`crates/kiln_parse/tests/redecl_index.rs` compiles generated namespaces
both ways and asserts that the diagnostics, the AST dump and every
declaration's redeclaration chain (`prev`, `INVALID`) are equal. The
namespaces hold hidden friends, overload sets, function templates with
different heads, friends instantiated from class templates,
using-declarators, invalid, deleted and retyped declarations, members
of an inline namespace and class members, each past the 32-entry
threshold.
