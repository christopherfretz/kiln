# WP-1473 — regressions found by the second full run of GCC's C++ testsuite

Each rule below is a behaviour kiln had at the first run (`604edce44`)
and lost to a later fix row; the second run found them. The other rules
WP-1473 restored are stated where they belong: `spec/sema.md` (C++11
implicit `const`, in-class `constexpr` static data members before C++17,
qualified names of a sibling class), `spec/sema-class.md` §5.5 (the
second step of a copy-initialization), `spec/sema-overload.md`
(CWG2918), `spec/sema-templates.md` (converted constant expressions,
`__is_pod` in C++98), `spec/parse.md` (`explicit` on a friend) and
`spec/landed/sema-templates/WP-1448.md` (explicit instantiation scope in
C++98).

- **By-copy capture of a reference** ([expr.prim.lambda.capture]/10): an
  entity captured by copy whose type is a reference gets a member of
  that reference type; a reference is never incomplete or abstract
  ([basic.types.general]/5), so `check_by_copy_capture` checks only an
  object type. `int (&f)() = g; [f] { return f(); }` is valid
  (`expr.prim.lambda.capture/by-copy-function-reference-run.cpp`).
- **Empty parenthesized pack expansion of an array** ([temp.variadic]/7,
  [dcl.init.general]/16.4): `T a[N](t...)` with an empty pack is
  `T a[N]()`, value-initialization ([dcl.init.general]/9.2), in every
  mode; `paren_init_rejected` rejects only a non-empty list before C++20
  (`dcl.init.general/paren-init-empty-pack-array-run.cpp`).
- **A parameter type deduced from a value** ([temp.deduct.type]/20):
  before C++17 only an array bound deduces `T` of `template<class T, T
  N>` (the value has type `std::size_t`, `bound_value_type`); a
  template-id's argument value (`A<0>` for `A<N>`) leaves `T` undeduced.
  From C++17 `deduce_nttp_type` deduces it from the argument's type. A
  template-id argument of type `std::size_t` is not told apart from a
  bound (`temp.deduct.call/nontype-type-from-template-id-cxx11.cpp`).
- **Friend destructor template** ([class.dtor]/1): `template<int> friend
  A::~A();` is "destructor cannot be declared as a template" at the `~`
  and declares nothing (`declare_special_member_friend`;
  `class.friend/friend-explicit-and-destructor-template.cpp`).
