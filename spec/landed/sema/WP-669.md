# WP-669 — range-v3 0.12.0 built and tested with kiln: sema fixes

Robustness wave 1 (M8): range-v3 0.12.0 was configured with its own CMake
build (C++20, tests on), compiled with kiln, and its ctest suite run.
The build log, the per-cluster triage and what remains are in
docs/status/oss/range-v3.md. Each behaviour below was a cluster of failed
translation units; each has a conformance test and a sentence in the
spec named.

## Changes

- **Two-stage implicit move before C++23** ([class.copy.elision]/3,
  [expr.prim.id.unqual]/4). In C++20 and earlier, `return x;` of an
  implicitly movable entity first tries the copy-initialization with `x`
  as an xvalue in a SFINAE frame and falls back to the lvalue when that
  fails other than by choosing a deleted function; `decltype(auto)` of
  `return (x);` is `T&`. spec/sema.md "Implicit move in `return`".
  Test: tests/conformance/class.copy.elision/p3-cxx20-two-stage.cpp.
- **Partially substituted expression pack expansions in template
  argument lists** ([temp.variadic]/5). `B<P<Ts, Us>::value...>` in a
  member template of `A<Ts...>`, met while only `Ts` is known, stays one
  expansion until `Us` is supplied. spec/sema-templates.md §7.2.
  Test: tests/conformance/temp.variadic/p5-partial-expr-expansion-member-template.cpp.
- **Bound member functions in `decltype` and `noexcept`**
  ([expr.mptr.oper]/6, [expr.ref]/6.3.2). `decltype(obj.*pmf)`,
  `noexcept(obj.f)` and builtin function names there are ill-formed, so
  substituting one is a deduction failure (SFINAE). spec/sema.md
  `act_on_decltype`. Tests:
  tests/conformance/expr.mptr.oper/p6-bound-member-unevaluated.cpp,
  tests/conformance/expr.mptr.oper/p6-bound-member-unevaluated-sfinae.cpp.
- **A base class conditional operand is never converted to the derived
  class** ([expr.cond]/4.3). `c ? B() : D()` with a converting
  constructor `D(B)` is a `B`, not ambiguous. spec/sema-templates.md
  [expr.cond]/4 class unification. Test:
  tests/conformance/expr.cond/p4-base-not-converted-to-derived.cpp.
- **`&C::m` of a dependent-type member** ([expr.unary.op]/3) stays a
  pointer to member when `this` is available, and **no `this` in a
  friend function's declarator** ([expr.prim.this]/2). spec/sema.md
  "this in the declarator", spec/sema-templates.md `&L::m`. Tests:
  tests/conformance/expr.unary.op/p3-qualified-member-pointer-dependent-type.cpp,
  tests/conformance/expr.prim.this/p2-not-in-friend-declarator.cpp.
- **Deduced template template arguments are checked**
  ([temp.arg.template]/3, [temp.deduct.type]/8). A template template
  argument deduced for a partial specialization or a function template
  must match its parameter, else deduction fails: `T<Ts...>` does not
  match `integer_sequence<int>` for `template<class...> class T`.
  spec/sema-templates.md §4.4 step 3. Test:
  tests/conformance/temp.arg.template/p3-deduced-argument-checked.cpp.
- **A trailing pack may be empty in clang 22 template template
  matching** ([temp.arg.template]/4). `template<class, class...> class`
  takes `template<class> class` at `-fclang-compat=22`.
  spec/sema-templates.md §3.2.1 (clang 22 matching). Test:
  tests/conformance/temp.arg.template/p3-trailing-pack-may-be-empty.cpp.
- **A constant does not deduce from a value-dependent argument in
  partial ordering** ([temp.deduct.partial]/3, [temp.func.order]/3).
  `f(ie<I, 1>)` is more specialized than `f(ie<I, N>)`.
  spec/sema-templates.md §6.7 step 4. Test:
  tests/conformance/temp.func.order/p3-constant-argument-more-specialized.cpp.
