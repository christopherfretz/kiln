# WP-1248 — consteval call frames in the context of an instantiation a reflection query requires

The rule is spec/sema-templates.md §10.2 ("Instantiations a reflection
query requires"); the Oven side is spec/oven.md "Interface"
(`Oven::frame_mark`, `Oven::paused_call_notes`).

- **Repro** (reported against kiln 1.0.0 by the reference workload's
  maintainers; names neutralized):

  ```cpp
  #include <meta>
  struct Shape { virtual int area() = 0; };
  template <class T> struct Crate { T item; };
  consteval bool probe(std::meta::info t) { return std::meta::is_complete_type(t); }
  consteval bool walk() { return probe(^^Crate<Shape>); }
  static_assert(walk());
  ```

  kiln 1.0.0 (`kiln++ -std=c++26 -freflection -fsyntax-only`) printed
  the error and the instantiation note only:

  ```
  k3.cpp:3:37: error: field type 'Shape' is an abstract class
  k3.cpp:4:50: note: in instantiation of template class 'Crate<Shape>' requested here
  k3.cpp:2:28: note: unimplemented pure virtual method 'area' in 'Shape'
  ```

  GCC 16.1 (`g++-16 -std=c++26 -freflection -fsyntax-only`, the
  reflection oracle) names the evaluation's frames:

  ```
  k3.cpp: In instantiation of 'struct Crate<Shape>':
  k3.cpp:4:77:   required from here
  k3.cpp:6:19:   in 'constexpr' expansion of 'walk()'
  k3.cpp:5:37:   in 'constexpr' expansion of 'probe(^^Crate<Shape>)'
  k3.cpp:3:37: error: cannot declare field 'Crate<Shape>::item' to be of abstract type 'Shape'
  k3.cpp:2:8: note: because the following virtual functions are pure within 'Shape':
  ```

  clang 22 has no reflection (`clang++-22: error: unknown argument:
  '-freflection'`).

  kiln now:

  ```
  k3.cpp:3:37: error: field type 'Shape' is an abstract class
  k3.cpp:4:50: note: in instantiation of template class 'Crate<Shape>' requested here
  k3.cpp:5:32: note: in call to 'probe(^^Crate<Shape>)'
  k3.cpp:6:15: note: in call to 'walk()'
  k3.cpp:2:28: note: unimplemented pure virtual method 'area' in 'Shape'
  ```

- **Cause.** The instantiation context notes came from sema's
  instantiation stack alone; the constant evaluation that asked for the
  instantiation (paused in `SemaBridge::meta`) was invisible to them.
- **Fix.** One hook for every reflection op: `Bridge::meta`
  (`crates/kiln_sema/src/oven_bridge.rs`) pushes the instantiation
  stack's depth and the paused evaluation's `Oven::frame_mark` on
  `InstState::meta_calls` for the call. `Sema::inst_context_notes`
  (`crates/kiln_sema/src/templ/stack.rs`) appends, after the outermost
  frame pushed during the call, `Oven::paused_call_notes`: the Oven's
  existing failure backtrace printer (`Oven::call_stack`,
  `crates/kiln_oven/src/notes.rs`) with its elision, rendered only when
  the error prints and only while the Oven sema holds (lent back by
  `lend_oven`) is still paused in that call. The notes are free-text
  diagnostics (`Diag::text_note`, `crates/kiln_diag/src/diag.rs`). Any op
  that instantiates through `lend_oven` is covered, including
  `reflect_constant`.
- **Tests.** `tests/conformance/meta.reflection.queries/`
  `is-complete-type-instantiation-frames.cpp` (the repro; twelve frames
  with the default elision), `meta.reflection.member.queries/`
  `members-of-instantiation-frames.cpp` (also an evaluation inside a
  class template instantiation: its note follows the frames),
  `meta.reflection.substitute/substitute-instantiation-frames.cpp`
  (`is_complete_type` and `size_of` of a `substitute` result),
  `meta.reflection.layout/size-align-instantiation-frames.cpp`, and
  `meta.reflection.extract/static-member-instantiate-neg.cpp` (now with
  the frame). All are `compile-fail` with `oracle: gcc` (GCC 16.1
  rejects each) and kiln's notes pinned by `strict-diags`: `verify` is
  not run under GCC (spec/harness.md "verify tests").
- **Deviations.** GCC prints the frames before the error, outermost
  first, and sometimes omits the outermost one; kiln keeps clang's note
  order (innermost first, after the instantiation note). An error in an
  instantiation that a nested evaluation started by the call requires
  (an `ensure_body` inside it) prints without the frames, and a frame
  elided by `-ftemplate-backtrace-limit` takes them with it.
