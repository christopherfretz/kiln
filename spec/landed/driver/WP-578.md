# WP-578 — -MD / -MMD dependency files when compiling

Extends spec/driver.md "Dependency output" (and drops the "not
implemented yet" entries for `-MD`/`-MMD` with `-fsyntax-only` and with a
codegen action, deviation 13). Oracle: clang++-19 (GCC agrees except
where noted).

## Driver

- `-MD` / `-MMD` (with `-MF`, `-MT`, `-MQ`, `-MP`) work with
  `-fsyntax-only`, `-S`, `-c` (also with `-emit-llvm`) and when compiling
  sources for a link, not only with `-E`. The action runs as usual; the
  dependency list is the same `deps::DepList` the `-E` path fills
  (`Job::build_preprocessor`), and the rule is rendered and named by the
  shared `deps::deps_text` / `deps::dep_destination`.
- File: `-MF`, else the `-o` value with its extension replaced by `.d`,
  else `<input stem>.d` in the working directory. With `-o` when linking
  several sources every rule goes to `<output>.d` (the last input's
  remains), as clang's `getDependencyFileName` names it (GCC names
  them `a-<stem>.d` when linking without `-o`).
- Target: `-MT` / `-MQ` in order, else the `-o` value, else
  `<input stem>.o`.
- The rule is written once preprocessing reached the end of the input,
  even when Sema or code generation then fails (clang and GCC keep the
  file). After a fatal error the preprocessor is drained to the end (its
  diagnostics are dropped by the engine) so every header is listed. An
  `#include` that names a missing file writes no rule (clang
  `SeenMissingHeader`, tracked by `DepCallbacks::inclusion_directive`).
- A header found by `__has_include` but never included is listed, as
  clang lists it (GCC does not); a header skipped by `#pragma once` or an
  include guard is listed once.
- `-E -MD` is unchanged: no file after any error (deviation 13).

## Tests

`crates/kiln_driver/tests/depfiles.rs`: `-c -MMD -MF -MT` (system
headers absent), `-c -MD` (`<vector>` present, first-inclusion order),
the default names (`-o x/y.o` -> `x/y.d`, `-S -o q.s` -> `q.d`, `-MQ`
quoting), `-MP`, `-fsyntax-only -MMD` and `-MF -`, two sources linked in
one command, and the error cases (a Sema error keeps the file, a missing
header writes none). The `-MMD` files are compared byte for byte with
clang++-19's when it is installed.
