# WP-1027 — `--help` refresh, release archive ships the 1.0 docs

Also covers WP-1024 (`--llvm-dir=` in `--help`) and WP-1028 (the README
links dangled inside a release archive).

## `--help`
- `crates/kiln_driver/src/help.rs` `HELP` replaces the old short list
  (which still said "-g (ignored)"). It uses clang's layout: `OVERVIEW`,
  `USAGE`, then one block per option group. The groups are actions,
  language, preprocessor, dependency output, target and toolchain, code
  generation, debug information, sanitizers and coverage, modules,
  linking, diagnostics, compile-time evaluation, kiln development and
  information.
- Kiln-only options are marked `[kiln]`. These are `-fkiln-*`,
  `--llvm-dir=`, `-fclang-compat=`, `-fconstexpr-memory=` and
  `-fconstexpr-report=`. Hidden options (`--driver-mode=`,
  `-fkiln-crash-for-testing=`) are not listed. The text names kiln, never
  clang as itself, and fits in 80 columns.
- spec/driver.md "`-v`, `--version`, `--help`" describes the help text.
  The options table no longer calls a nameless `-fmodule-file=<path>`
  "ignored" (spec/modules.md §11.6).
- Evidence is in `help::tests`:
  - `every_listed_option_is_accepted` expands every listed form, with
    optional `[...]` parts on and off and each `<placeholder>` replaced
    by a valid sample, then parses `<form> t.cpp` with `Args::parse`. It
    asserts no `ArgError` and no pending diagnostic option error, over
    more than 150 command lines.
  - `lists_the_option_groups_and_marks_kiln_only` checks that the
    required groups and flags are present and that `[kiln]` sits exactly
    on the kiln-only options.
  - `says_kiln_and_fits_80_columns` checks the text names kiln and fits
    in 80 columns.

## Release archive docs
- `dist::DOCS` installs these flat in `share/doc/kiln/`: README,
  CHANGELOG, CONTRIBUTING, SECURITY, both licenses, and
  docs/{COMPATIBILITY,KNOWN_ISSUES,STABILITY,USER_GUIDE}.md.
- `dist::rewrite_links` (spec/harness.md "Dist" step 3) rewrites the
  Markdown links:
  - A link to a shipped doc becomes its bare file name, anchor kept.
  - A link to any other checkout path becomes a GitHub URL at tag
    `v<version>`: `raw` for an HTML `src=`, `tree` for a directory,
    `blob` otherwise.
  - A link to a path the checkout lacks is an error.
- `xtask/src/doclinks.rs` is a reusable Markdown link scanner and checker.
  It skips fenced code and inline code, and checks heading slugs with
  GitHub's rule plus HTML `id`/`name`.
- `doclinks::check_tree` checks the installed tree in `assemble` and
  again in `dist --check` on the extracted archive (`check_layout`). A
  broken link fails either step.
- Evidence:
  - `dist::tests::layout_and_deterministic_archive` (all ten docs present,
    `check_tree` empty, README links flat).
  - `dist::tests::rewrites_links_for_the_flat_layout`.
  - `doclinks::tests` (4 tests).
