# WP-1022 — User-facing 1.0 documentation: README, user guide, known issues, changelog, contributing, security

1.0 work item A8: the documents a user or contributor reads first. Docs
only; no behaviour changes. The note lives under `driver` because the user
guide documents the driver's command line and there is no `spec/docs.md`.

## Documents
- `README.md`: pitch, headline numbers (each linked to the status page it
  comes from), quick start from the release archive, building from
  source (Rust 1.95, `cargo xtask dist`), status table, documentation
  index, a Development section.
- `docs/USER_GUIDE.md`: install and run-time dependencies, CMake, Meson
  and autotools (consistent with docs/COMPATIBILITY.md "Build systems"),
  language modes (`-std`, reflection on by default at C++26, contracts,
  `-fclang-compat`), modules, the Oven's limits and reports, kiln-only
  flags and differences from clang, environment variables, `-g`,
  sanitizers, coverage, targets and LLVM versions, crash reports.
- `docs/KNOWN_ISSUES.md`: platforms, C mode, build systems, modules,
  sanitizers and coverage (PGO, WP-1003), accepted-and-ignored flags,
  attribute classes, accepts-invalid totals, the libc++ 22 leftovers, OSS
  projects with gaps; each item names its BACKLOG row where one exists.
- `CHANGELOG.md` (Keep a Changelog, `## [1.0.0] - unreleased`),
  `CONTRIBUTING.md`, `SECURITY.md` (GitHub private vulnerability
  reporting; scope: crashes on untrusted input, Oven resource
  exhaustion).

## Rules for these documents
- Every number cites a page in the repository that records how it was
  measured; every flag documented exists on main (spec/driver.md,
  `kiln++ --help`).
- Text that depends on work not yet on main carries
  `<!-- update when WP-NNN lands -->` (WP-1016: LLVM discovery and
  default 22). The WP-917 module-file text was resolved against
  spec/landed/modules/WP-917.md once it landed.
