# WP-706 — `-fcontract-evaluation-semantic=`

- spec/driver.md "Options": `-fcontract-evaluation-semantic=` takes
  `ignore`, `observe`, `enforce` (the default) or `quick_enforce`
  (`quick-enforce` too), GCC's spelling, into
  `Args::contract_semantic`; any other value is "unsupported argument
  'v' to option '-fcontract-evaluation-semantic='" (exit 1). The
  syntax and codegen commands pass it as
  `ParseOptions::contract_semantic`, which becomes
  `Ast::contract_semantic` (spec/contracts.md §6.1).
- `__cpp_contracts` is `202502L` at C++26 (kiln_pp KILN_FEATURES).

Tests: `crates/kiln_driver/src/args.rs` (`contract_evaluation_semantic`),
`tests/conformance/cpp.predefined/contracts-macro.cpp`,
`contracts-macro-cxx23.cpp`, every `run-ignore.cpp` under
`tests/conformance/*contract*`.
