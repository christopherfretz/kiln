# WP-1128 — `-ftime-trace` coverage and `-fconstexpr-profile` tails (with WP-1147)

Closes WP-1115's and WP-1116's open ends (spec/driver.md "Time trace",
"Constexpr profile"; spec/oven.md "Reporting protocol"). Each event was
checked against `clang++-22 -ftime-trace -ftime-trace-granularity=0`
(and clang 19) on a small TU; kiln records an event only where it does
the work clang's event times.

## Time trace events
- Sema folds: `trace_fold` (`kiln_sema` `oven_bridge.rs`) is a
  `trace::Scope` whose detail (the expression's range, clang's
  `ExprTimeTraceScope`) is built only while a trace runs.
  `fold_rvalue` records `EvaluateAsRValue`, `fold_rvalue_int`
  `EvaluateAsInt` (nothing nested, as clang); `fold_rvalue_untraced` is
  the body, for folds that are part of a traced evaluation.
  `check_for_int_overflow` records one `EvaluateForOverflow` per operator
  root of its walk; the walk's folds record nothing. A CFG branch's
  condition (`cfg/truth.rs` `known_truth`) records
  `EvaluateAsBooleanCondition` holding `EvaluateAsRValue` (clang's
  `tryEvaluateBool`).
- `CheckConstraintSatisfaction` (`templ/concepts/sat.rs`): at the top of
  `check_concept` / `check_constraints`, cache hits included, detail the
  template-id's location, as clang 22's. A check whose innermost frame,
  past atom substitutions, is a satisfaction check records none (clang
  22 normalizes the concept-id into the enclosing check).
- `BuildCFG` (`cfg/body.rs` `cfg_ensure`), no detail.
- `-g`: `DebugType` (`kiln_codegen` `debuginfo/types.rs` `di_type`, cache
  hits included, the sugared type) and `DebugGlobalVariable`
  (`debuginfo/func.rs` `di_global_var`, the qualified name).
- `WriteAST`: the module file write (`pp_cmd.rs` `write_module_file`,
  inside `Frontend` as clang's for a module interface) and the PCH record
  write (`pch.rs` `write_pch`, after `Frontend`). `--precompile` and a
  header precompile now write traces (`time_trace::writes`):
  `--precompile -o m.pcm` gives `m.json`, `-x c++-header h.h -o h.pch`
  gives `h.pch-h.json`, as clang 19 and 22.

## Trace files
- Linking with `-ftime-trace=<dir>`: each input's trace is
  `<dir>/<stem>-<6 hex>.json`, after a clang-like temporary object name
  (`TempDir::suffix`, a hash of the run's temporary directory and the
  input's index), so inputs and runs never overwrite one another.
- A trace that cannot be written is `unable to open output file`, and
  the exit status is unchanged (clang 19 and 22 exit 0); `-c`, linking,
  `-E` / `-M` and precompiles alike.

## Constexpr profile
- `-fconstexpr-report` rows and the total carry `reclaimed_bytes`
  (`kiln_oven` `report.rs`; spec/oven.md "Reporting protocol").
- A module source named by `-fmodule-file=<name>=<source>` is compiled in
  the importer's Oven: its evaluations are reported with the importer's
  (profile, summary and report), at the module source's locations. A
  module cache build reports nothing, its `-fconstexpr-report` included
  (`module_cache.rs` `StdCache::build`).

## Overhead

recorder's `enabled()`; the profile's counters were already gated).

branch, interleaved runs (median of 11; 21 for the last), wall ms:
