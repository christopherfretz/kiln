# WP-920 — Driver toolchain probes, kiln's identity, reflection on by default, Meson/autotools smoke

Closes WP-596 (`-MG`). Operator decisions Q3 (identity) and Q7
(reflection default), 11-08.

## Toolchain probes
- `crates/kiln_driver/src/lib.rs` `immediate()`, spec/driver.md "Toolchain
  probes": `-dumpversion`, `-dumpmachine`, `-print-target-triple`,
  `-print-multiarch`, `-print-sysroot`, `-print-resource-dir` answered by
  kiln; `-print-file-name=` (resource dir first), `-print-prog-name=`,
  `-print-libgcc-file-name`, `-print-search-dirs` delegated to the backing
  clang++ with kiln's link toolchain arguments (`toolchain_link_args`).
  First probe in clang's `HandleImmediateArgs` order wins.
- `-dumpversion` is the compatibility version (`22.1.8`; `19.1.7` under
  `-fclang-compat=19`), equal to `__clang_major__.__clang_minor__.
  __clang_patchlevel__`, so configure-time clang thresholds hold.
- Linker inputs (`-l`, `-Wl,`, `-Xlinker`) count as inputs, as clang's:
  `kiln++ -Wl,--version` runs the linker alone (Meson's linker probe).

## `-MJ`, `-dD`, `-dI`, `-MG`
- `-MJ <file>`: `crates/kiln_driver/src/cdb.rs`, clang's
  `DumpCompilationDatabase` fragment per frontend job; none under `-###`
  (clang's). Driver error `drv_compilation_database`.
- `-dD` / `-dI`: `kiln_pp` printer markers for `#define`/`#undef` and
  `#include` (`/* clang -E -dI */`); `-dI` output byte-identical to
  clang 19, `-dD` identical apart from the predefine order.
- `-MG`: a missing header under `-M`/`-MM` is listed as a generated
  dependency (`deps.rs`); without `-M`/`-MM` the error
  `drv_mg_requires_m_or_mm`.

## Identity (Q3)
- `__VERSION__` is `"kiln <version>"`; `--version`, `-v`, `-###` already
  said `kiln version <v>`. The `__clang__` family stays. Every identity
  string reads `kiln_driver::version()`.
- Build systems: CMake (macros: Clang 22.1.8) and autotools (`__GNUC__`,
  `-print-prog-name=ld`, `-v`) work unchanged. Meson 1.12.1 requires
  `clang` in `--version` text, so it cannot recognise kiln without the
  word; options (a) wrapper / native file (shipped), (b) a
  `clang-compatible <ver> (kiln version <v>)` banner, (c) (b) opt-in are
  an operator decision (docs/COMPATIBILITY.md "Build systems"). The OSS
  harness's `kiln-cxx` prints the (b) line under `KILN_OSS_VERSION_SHIM`.

## Reflection on by default (Q7)
- `Args::reflection_for`: on at C++26 unless the last of
  `-f[no-]reflection` is `-fno-reflection`. Below C++26 unchanged: off,
  `-freflection` accepted and ignored. spec/reflection.md §1.4.
- Cost: docs/status/oss.md "Reflection default cost (WP-920)".
