# WP-927 — Relocatable install layout, version plumbing, `cargo xtask dist`, release workflow, STABILITY.md

1.0 work item A3: kiln ships as a relocatable binary archive.

## Install layout and resource discovery
- spec/driver.md "Installation layout": `bin/kiln`, `bin/kiln++ -> kiln`,
  `lib/kiln/<major>/{include,predefines}` (the resource directory),
  `share/doc/kiln/` (README, both licenses, COMPATIBILITY, STABILITY).
- `toolchain::default_resource_dir` (spec/driver.md "Toolchain"):
  `-resource-dir`, `$KILN_RESOURCE_DIR` (non-empty), the install path
  next to the canonicalized `current_exe` (`install_resource_dir`), the
  upward `resource/` search, and the compiled-in source tree only without
  the `dist` cargo feature. A `dist` binary holds no build-host path; its
  last resort is the (missing) installed path.
- Evidence: `crates/kiln_driver/tests/install_layout.rs` (a hard-linked
  binary in a fake prefix: direct, `kiln++` symlink, a symlink to it
  elsewhere, `PATH`; env and flag precedence; incomplete tree falls back).
  Source-tree behaviour is unchanged (the existing `print_resource_dir`
  test).

## Version
- `kiln_driver::version` (spec/driver.md "Version"): `VERSION`, `MAJOR`,
  `MINOR`, `PATCH` from `CARGO_PKG_VERSION*` (the workspace version, not
  bumped), `GIT_SHA` from `build.rs` (`$KILN_GIT_SHA`, else `git
  rev-parse --short=12 HEAD` when the workspace is the work-tree root;
  no git, no sha, no failure), `long_version()`.
- `__KILN_PATCH__` joins `__KILN_MAJOR__`/`__KILN_MINOR__`
  (`PredefConfig::kiln_version` is now a triple; spec/pp.md,
  spec/driver.md "Predefines"). `-v` and `!llvm.ident` read `VERSION`.
  The `--version` text is untouched (WP-920 owns it; `long_version()` is
  there for it).

## `cargo xtask dist`
- spec/harness.md "Dist": `dist` profile (`release`, unstripped) +
  `dist` feature, `--remap-path-prefix` of checkout, target dir,
  `$CARGO_HOME`, `$RUSTUP_HOME`; `objcopy --only-keep-debug` /
  `--strip-debug --add-gnu-debuglink=kiln.debug`; deterministic `tar.xz`
  (sorted, 0:0, `SOURCE_DATE_EPOCH`/HEAD time, `xz -9 -T1`) of the
  stripped and the unstripped tree; `SHA256SUMS`.
- `--check`: extracted, `KILN_*` scrubbed, cwd outside the checkout:
  `--version`, `-print-resource-dir` (three ways), hello world compiled,
  linked and run, a constexpr-heavy TU, a `<meta>` TU with
  `-freflection`, no build-host path in either binary or any output, the
  debuglink CRC.
- Not in `ci` (several minutes); unit tests of the layout, a
  byte-identical re-archive, the CRC and the path scan run in `cargo
  test`.

## Release workflow and policy
- `.github/workflows/release.yml`: `v*` tags only; `dist --check` on
  ubuntu-24.04-arm and ubuntu-24.04 in the CI container; the tag must
  equal `v<workspace version>`; four archives + merged `SHA256SUMS` on a
  draft release. Validated with actionlint 1.7.7.
- docs/STABILITY.md (linked from README "Installing"): semver scope,
  deprecation, MSRV 1.95, and the crates.io decision (not published).
