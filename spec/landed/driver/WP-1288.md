# WP-1288 — Driver: `-rpath <dir>`, `-Wa,` / `-Xassembler`

Extends spec/driver.md (linker options, "Unused inputs", assembler options).

## `-rpath <dir>`

- A linker input with a separate value (clang `-rpath` is
  `Separate`, `LinkerInput`): `LinkOptKind::Rpath`, passed to the link as
  `-rpath <dir>` in command-line order.
- It counts as an input for `no input files`, like `-l` and `-Wl,`.
- In a compile-only phase it warns `-rpath <dir>: 'linker' input unused`.
  A missing value is "argument to '-rpath' is missing (expected 1 value)".
- sqlite's configure probes `-rpath /usr/local/lib` first; it no longer
  falls back to `-Wl,-rpath`.

## `-Wa,<list>` and `-Xassembler <arg>`

- Parsed into `Args::asm` (`AsmOpt`: the option as written, the option
  named in errors, the values; `-Wa,` split at commas).
- kiln has no assembler step: `llc` writes the object and already emits
  `.note.GNU-stack`, so `--noexecstack` needs nothing.
  `Args::asm_check` accepts what clang 19's integrated assembler accepts
  on Linux (spec/driver.md lists them). `--compress-debug-sections[=t]`
  sets the `-gz` compression when there is no `-gz`.
- Checked only when a source is assembled (`-c`, or a link), as clang:
  any other value is `unsupported argument '<v>' to option '-Wa,'` (or
  `'-Xassembler'`), exit 1. `-E`, `-fsyntax-only`, `-S` and `-emit-llvm`
  ignore them.
- With nothing to assemble: `-Wa,...` is `argument unused during
  compilation: '-Wa,...'`; `-Xassembler <a>` is warned the same way
  under `-c` only (clang's link job claims it silently).
- Not accepted, unlike clang: `--crel` (clang requires
  `--allow-experimental-crel`), `--defsym`, `--version`.
- zstd's CMake build passes `-Wa,--noexecstack`; it is no longer dropped.

## Not changed

- CMake's ASM compiler identification: CMake runs `--version` (and `-V`,
  `-qversion`, ... for other vendors) and needs `clang version` in the
  output to say Clang. kiln's `--version` says `kiln version <v>` by
  decision (docs/COMPATIBILITY.md "Build systems"), so the ASM compiler
  ID stays unknown and CMake falls back to its generic ASM rules. kiln
  already fails `-V` and `-qversion` with exit 1, as clang does.
- Linker inputs under `-E` and `-fsyntax-only` are not warned unused
  (clang warns them); this predates WP-1288 and applies to `-l`, `-Wl,`
  and `-Xlinker` too.
