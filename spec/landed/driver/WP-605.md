# WP-605 — Driver accepts the common GCC/clang codegen flags (`-fstack-protector*`, `-f{function,data}-sections`, unwind tables, `-march`, …)

Adds spec/driver.md "Codegen flags" (the three-class table), deviation 19
and the new `llc` arguments, and spec/codegen.md "Hardening and overflow
options". Oracle: clang++-19 (IR compared exactly by `tests/codegen/`).

## Driver

- `CodegenFlags` (`crates/kiln_driver/src/codegen_flags.rs`, field
  `Args::codegen`) parses the flags; within each `-fX`/`-fno-X` pair the
  last wins.
- Class 1, honoured: `-fstack-protector{,-strong,-all}` /
  `-fno-stack-protector` (`ssp`/`sspstrong`/`sspreq`); the unwind-table
  pair (`uwtable`, `uwtable(sync)`, none; the default asynchronous
  `uwtable` stays); `-f[no-]plt` (`nonlazybind`, `RtLibUseGOT`, no
  `dso_local` function declarations under `-fno-pic`);
  `-ffunction-sections` / `-fdata-sections` (`llc -function-sections` /
  `-data-sections`); x86-64 `-march=<clang x86 CPU>` (`"target-cpu"`),
  `-march=native` / AArch64 `-mcpu=native` (no `"target-cpu"`, `llc
  -mcpu=native`), `-mtune=<cpu>` (`"tune-cpu"`; `native` adds nothing);
  `-f[no-]wrapv`, `-f[no-]wrapv-pointer`, `-f[no-]strict-overflow` (no
  `nsw`, no `inbounds` on pointer arithmetic; at compat 22 none on field
  GEPs); `-f[no-]delete-null-pointer-checks` (`null_pointer_is_valid`, no
  `nonnull`); `-Wp,<list>` and `-Xpreprocessor <arg>` spliced into argv
  (`-Wp,-MD,<f>` is `-MD -MF <f>`).
- Class 2, ignored: `-f[no-]stack-clash-protection`,
  `-fcf-protection[=full|branch|return|none]`, `-f[no-]common`,
  `-fexcess-precision=fast|standard|16`, `-f[no-]math-errno`,
  `-fstack-usage`, `-gz[=none|zlib|zstd]`, `-fno-trapv`,
  `-fno-short-enums`. Bad values are `invalid value` (`-fcf-protection=`)
  or `unsupported argument` errors.
- Class 3, rejected: `drv_unsupported_flag` "'<flag>' is not supported by
  kiln" for `-ftrapv`, `-fshort-enums`, `-fsanitize*`, `-fno-sanitize*`,
  `-fcoverage-mapping`, `-fprofile-arcs`, `-ftest-coverage`,
  `--coverage`, `-fprofile-{instr-,}generate[=]`,
  `-fprofile-{instr-,}use[=]`.
- The Oven is unchanged by `-fwrapv` (deliberate divergence from GCC,
  deferred).

## Codegen

- New `CodegenOptions` fields: `stack_protector`, `unwind_tables`,
  `no_plt`, `wrapv`, `wrapv_pointer`, `null_pointer_is_valid`,
  `target_cpu`, `tune_cpu`; `Cg::field_gep`, `Cg::gep_arith`,
  `Cg::nsw_if`, `Cg::vla_nsw`; `visibility::assume_dso_local` takes
  `no_plt`.
