  CMake"; §8 (the libc++ self-tests); §11.10 (the bullet now points to

- spec/driver.md: the options table, "Modules", new "Module cache",

- spec/libcxx.md: `MODULE_DEPENDENCIES:` and "RUN lines".

spec/modules.md §11.12 has the design. This file records what landed and
where.

## What landed

- **Cache** (`crates/kiln_driver/src/module_cache.rs`). `for_job` builds
  a `kiln_pp::StdModuleCache` hook (`crates/kiln_pp/src/modules.rs`,
  `ModuleOptions::std_cache`, consulted only at lookup step 4). The hook
  is wired in `pp_cmd.rs` `build_preprocessor`. It works as follows:
  - Root: `-fmodules-cache-path=`, else `$XDG_CACHE_HOME/kiln/modules`,
    else `~/.cache/kiln/modules`.
  - Key: the hash of kiln's identity, the §11.4 fingerprint, the
    predefines, the search list and the libc++ module sources.
  - Each entry holds a stamp of every file read.
  - Writes are a temporary file plus a rename, with no lock.
  - A miss runs `--precompile` in-process on its own thread.
  - Any failure falls back to part A, with a `-v` remark.
- **Flags** (`args.rs`): `-fmodules-cache-path=<dir>` (an empty value
  turns the cache off) and `-f[no-]kiln-module-cache`. There are no new
  diagnostic ids, because no failure of the cache is a diagnostic.
- **`-print-file-name=libc++.modules.json`** (`lib.rs` `immediate`,
  `toolchain.rs` `libcxx_modules_json`): the manifest beside the libc++
  that `-stdlib=libc++` selects.
- **CMake**: the `scripts/oss/fixtures/modules` `stdapp` target
  (`CXX_MODULE_STD ON`, `stdmain.cpp` does `import std;`). The
  experimental UUID is chosen by `CMAKE_VERSION` before `project()`.
  `selftest.sh` `cmake_modules` builds with `-stdlib=libc++` and
  checks that:
  - CMake finds import std support;
  - kiln builds `std.cppm`;
  - `stdapp` runs;
  - neither touching the interface nor touching `stdmain.cpp` rebuilds
    the std module.
- **Harness**:
  - `%{libcxx_modules}` (`xtask/src/util/mod.rs`
    `libcxx_module_dir_of`; `test/runner.rs`, `test/directives.rs`,
    `test/mod.rs`), and placeholders in `module:` paths.
  - `XDG_CACHE_HOME=<target>/xdg-cache` for every compiler the suites
    run (`util::isolate_caches`).
  - libc++ `format.py`'s module build for `.sh.cpp` tests
    (`xtask/src/libcxx/run.rs` `module_build`, `Config::module_dir`).

## Measured

All figures are aarch64, the `harness` profile, `/usr/bin/time -v`, the
median of three. The program is `import std;` plus a small `main`, with
`-std=c++23 -stdlib=libc++ -c`:

- cold cache: 2.45 s / 139 MB;
- warm cache: 1.49 s / 98 MB;
- part A: 1.52 s / 95 MB;
- clang++-22 two-step: 1.62 s / 302 MB (precompile), then 0.47 s / 178 MB.

A warm hit equals part A, because a source capsule is replayed. Kind 2
(WP-985) is what makes the cache pay. An entry is 8.6 MiB plus an
88 KiB stamp.

CMake 3.31.6 with Ninja 1.12.1: `CXX_MODULE_STD` works with
`kiln++ -stdlib=libc++` and gate `0e5b6991-d74f-4b3d-a41c-cf096e0b2508`.

## Tests

- `crates/kiln_driver/tests/module_cache.rs` (7 tests, against a
  miniature libc++ sysroot):
  - miss then hit;
  - `std.compat` filling both entries;
  - invalidation by a header edit, a damaged module file, a new
    `std.cppm`, `-D` and `-fno-exceptions`;
  - racing misses;
  - an unwritable root;
  - location and switches;
  - the manifest.
- `module_cache.rs` unit tests: the root, the key separation, the
  stamps.
- `tests/conformance/module.import/import-std-two-step.cpp` (new) runs
  under kiln, clang++-22 and clang++-19.
- Converted from `skip(clang)` to two-step under clang: `import-std-format`,
  `import-std-ranges`, `import-std-hidden` and `import-std-compat`.
  `import-std-vector` stays `skip(clang)` as the test of kiln's implicit
  lookup.
- libc++ `libcxx/selftest/modules/`: 4 of 4 PASS under kiln and
  clang++-22 (3 were UNSUPPORTED).
- `xtask/src/libcxx/run.rs` unit tests: `module_build` and `module_dir`;
  `prepare` accepts `MODULE_DEPENDENCIES` in `.sh.cpp`.
- `scripts/oss/selftest.sh` `cmake_modules`: the `CXX_MODULE_STD` checks.

## Not in this step

- Eviction of old cache entries.
- A smaller `-MD` on a hit.
- The serialised-AST format that makes a hit cheaper: WP-985.
