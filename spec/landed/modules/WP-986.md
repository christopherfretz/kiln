# WP-986 — module tests in the module:/unit: harness forms

Extends spec/modules.md ("Tests": the converted tests and the coverage
note) and spec/harness.md (the `header-unit:` directive, its tests). The
two-step harness mode itself is WP-917 (spec/modules.md §11.7).

## What landed

- **Converted tests.** Every module test that was `skip(clang)` because
  the harness could not drive clang's separate module build now names
  its units with `module:` (and `unit:`) lines instead of `args:`
  sources and `-fmodule-file=` flags:
  - `run` tests, two-step under kiln and clang (§11.7):
    `module.interface/export-run.cpp`, `module.unit/partitions-run.cpp`,
    `module.private.frag/private-run.cpp`,
    `module.import/export-import-run.cpp`,
    `basic.start.dynamic/module-init-run.cpp`; and, still
    `skip(clang)` for a deliberate deviation rather than the harness,
    `basic.lookup.argdep/module-enum.cpp`, `module-enum-overload.cpp`
    (deviation 10), `basic.stc.thread/module-tls-run.cpp` (deviation 9)
    and `module.global.frag/gmf-dup-run.cpp` (deviation 7);
  - compile tests (kiln reads the sources, clang module files):
    `module.interface/visibility.cpp`, `module.import/import-order.cpp`,
    `basic.lookup.argdep/module-example.cpp`, and
    `module.reach/missing-import.cpp`, `missing-include.cpp`,
    `missing-include-dirs.cpp`. `visibility.cpp` and
    `missing-import.cpp` are `requires: clang>=22` (clang 19's wording
    for a module-linkage name differs).
  - `module.import/header-unit.cpp` and `header-unit-angled.cpp` through
    the new `header-unit:` directive.
- **Duplicates folded.** `two-step-partitions-run.cpp`,
  `two-step-module-init-run.cpp` and `two-step-gmf-dup-run.cpp` (WP-917)
  were the converted originals line for line and are gone; the old
  single-command form of `partitions-run.cpp` stays as
  `module.unit/single-invocation-run.cpp` (kiln only), the corpus's one
  test of part A's single `kiln++` invocation over module sources.
- **Harness** (`xtask/src/test/`): `header-unit: "<path>"` /
  `header-unit: <name>` (`directives.rs`, `HeaderUnit`); a clang builds
  each with `-fmodule-header=user|system` before the module units and
  every later compile reads it with `-fmodule-file=`
  (`runner.rs` `build_header_units`, `module_flags`); a `run` test with
  one is two-step; GCC is not compared. Kiln gets nothing (in-process
  header units, §3).

## Bugs

None found: every converted test passes under kiln (oracle clang 22 and
clang 19), under clang 19 and 22 as the compiler (where not
`skip(clang)`), and under `--bmi-kind 1` and `--bmi-kind 2`.
