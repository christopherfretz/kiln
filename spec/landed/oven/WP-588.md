# WP-588 — if consteval under non-manifest trial folds

The rule is spec/oven.md "Manifestly constant-evaluated context"
(`if consteval`). This file records where the fix lives and the tests.

- **Bug.** The Oven compiled an `if consteval` statement to its compound
  statement only (`if !consteval` to its else), on the premise that
  constant evaluation is always manifestly constant-evaluated. Trial folds
  are not: codegen folds `if (ice())`, `ice() && x` and `ice() ? a : b`
  with `try_fold` (`const_context` false), so such calls folded to the
  constant-evaluation answer (a function `f() { if (ice()) return 1; ... }`
  emitted `ret i32 1`), and libstdc++'s `char_traits::length`/`copy`,
  `_M_init_local_buf` and `std::construct_at` paths ran their
  constant-evaluation loops at run time.
- **Fix.** `crates/kiln_oven/src/compile.rs` `IfStmt`: both substatements
  are compiled, behind `IsConstEval [r]` (`aux` 16) and a conditional
  jump; `crates/kiln_oven/src/vm.rs` `Op::IsConstEval` reads
  `RunState::const_context` for `aux` 16 without the `-Wconstant-evaluated`
  check; `crates/kiln_oven/src/kbc.rs` documents the `aux`. The body stays
  memoizable (the memo key carries the context).
- **Tests** (`tests/conformance/stmt.if.consteval/`, oracle clang 19 and
  22): `trial-fold-run.cpp` / `trial-fold-O2-run.cpp` (the reproducer:
  plain `if`, `&&`, `?:`, a loop, a dynamic initializer), `manifest.cpp`
  (static_assert, constexpr/constinit variables, template argument, array
  bound, enumerator, case label, `if constexpr`, consteval wrappers),
  `is-constant-evaluated-run.cpp` (the same shapes with
  `std::is_constant_evaluated()`, and agreement with `if consteval`),
  `always-inline-run.cpp`, `char-traits-length-run.cpp` /
  `char-traits-length-O2-run.cpp` (a volatile counter only the run-time
  branch touches).
