# WP-1154 — expressions in an out-of-line member's signature, rebuilt in the current instantiation

WP-1154 closes the WP-1152 gap "a `decltype` operand is not rebuilt". The
rule is in spec/sema-class.md §8.3, under "Out-of-line declarator scope".
Every case is checked against clang 22 and clang 19.

- **The rule** ([temp.dep.type]/1, /6, [temp.over.link]/5). Before the
  declarator-id of an out-of-line member of a class template, the parser
  does not yet know the class, so `typename C<X>::T` and `C<X>::N` are
  dependent names. Once the declarator-id is known, the decl-specifiers'
  type is rebuilt in the current instantiation
  (`rebuild_in_current_instantiation`, clang's
  `RebuildDeclaratorInCurrentInstantiation`). WP-1152 rebuilt the type
  constructors; WP-1154 also rebuilds the expressions inside types
  (clang's `RebuildExprInCurrentInstantiation`):
  - a `decltype` operand: `decltype(typename C<X>::T())`,
    `decltype(C<X>::N + 1)`;
  - a value-dependent array bound: `W<char[C<X>::N]>`;
  - the `noexcept` operand of a function type:
    `NX<void() noexcept(C<X>::B)>`;
  - an expression template argument: `I<C<X>::N + 1>`;
  - `sizeof`, `alignof` and `noexcept` inside any of these.
  The rebuilt expressions are equivalent to the in-class ones, so the
  definition matches its declaration.
- **How.** `rebuild_ci_expr(e, qual)` runs the substituter with no
  argument levels (an identity substitution) in a current-instantiation
  mode, `Substituter::ci_rebuild`, inside the declarator scope:
  - every type is rebuilt by `rebuild_ci_type`, not substituted;
  - a `DependentScopeDeclRefExpr` `C<X>::m` whose qualifier names the
    current instantiation (`rebuild_ci_nns_record`) and where lookup
    finds `m` becomes the id-expression the class forms
    (`ci_member_ref`). A member of a dependent base, or a template-id,
    stays dependent.
  `rebuild_ci_expr_type` rebuilds `decltype` (through the substituter's
  `decltype_ty`) and a dependent-sized array; `rebuild_ci_compound`
  rebuilds a function type's `noexcept` operand; `rebuild_ci_type`
  rebuilds the expression arguments of a template-id.
- **Still not equivalent** (clang agrees): an expression that differs
  (`N + 2` for `N + 1`), and `decltype(sizeof(typename D<B>::T))` for
  the in-class `decltype(sizeof(T))` with `T` a non-dependent typedef:
  the written qualifier keeps the rebuilt operand instantiation-dependent,
  while the in-class one is not.
