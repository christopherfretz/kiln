# WP-501 — structural, link-compatible reflection mangling

- **Form.** A `std::meta::info` template argument mangles as
  `L <info-type> <kind> <operand> E`, which names the reflectee. It replaces
  WP-485's TU-local `L u6__info <id> E`. The kind letters and operand
  encodings are GCC 16.1's `write_reflection` (cxx-abi issue #208):
  `nu ty ta ns gs na vr fn dm en ct ft vt at co sb pa ba vl ob ds an`.
  Constructors are `C4` and destructors `D4`. The grammar, the per-kind
  table, dependent operands and the cost are in spec/reflection.md §8.3.
  The code is in `crates/kiln_abi/src/mangle/reflect.rs`; the
  dependent-operand path is `Mangler::reflect_expr`.
- **Modes.** `-fkiln-reflection-mangling=` selects
  (`kiln_abi::ReflectionMangling`; spec/driver.md):
  - `kiln` (the default) writes the info type as `u6__info`;
  - `gcc` writes it as `Dm` (builtin, not a substitution candidate) and
    gives an alias-template specialization the arguments of the underlying
    class specialization. It is byte-identical to `g++-16`;
  - `kiln-hashed` writes `h` and the FNV-1a-128 of the kiln body, as
    32 hex digits.
- **Linkage.** `value_externally_visible` asks
  `reflect::reflection_externally_visible`. The reflection has the
  reflectee's linkage, so `f<^^int>` and `S<^^int>::count` are
  `linkonce_odr` and shared across TUs again. These are internal:
  - local entities;
  - annotations, because their index is TU-local;
  - a data member spec whose type or annotations are internal.
- **Data member specs.** The Oven's DMS table is copied into
  `ReflectionTable::set_dms` (`DmsDesc`: type, name, alignment, width,
  `no_unique_address`, annotations) after the fold prepass
  (`kiln_codegen::emit_with_diags`), so the mangler can write
  `ds <type> _ [name] _ [align] _ [width] _ [n] <annotations>`.
- **Tests.**
  - `crates/kiln_driver/tests/reflection_mangling.rs`:
    - the 41-row per-kind table in both modes, checking linkage;
    - a two-TU kiln link (`two_translation_units_link`);
    - a kiln+g++-16 symbol check (`gcc_link_compat`).
  - `crates/kiln_codegen/tests/reflection_mangle.rs`: pinned forms,
    substitutions, determinism and 2000 specializations.
  - `crates/kiln_driver/src/args.rs` (`reflection_mangling`): the flag.
  - Bench shape S9 (`bench/reflect/s9.cpp`, spec/bench.md).
- **Known general GCC divergences.** These are not reflection-specific;
  see spec/abi.md §8.14:
  - anonymous-namespace `L`;
  - the empty non-type pack;
  - `sr` with a template-id qualifier;
  - `STB_GNU_UNIQUE` statics.
