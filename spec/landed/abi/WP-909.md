# WP-909 — `-fkiln-reflection-mangling=gcc` is the default

WP-879's scaling study (spec/landed/sema/WP-879.md) measured kiln's
vendor reflection mangling (`L u6__info <kind> <entity> E`) against
GCC 16.1's (`L Dm <kind> <entity> E`). The two cost the same time and
memory, the gcc form is 1-5% shorter, and it is byte-identical to
g++-16, so objects link with GCC-built ones. The operator decided on
11-09 that the gcc form is the 1.0 default. `kiln` and `kiln-hashed`
stay as experimental opt-in values of the flag. The rule is
spec/reflection.md §8.3; spec/abi.md, spec/driver.md and
spec/reflection-repr.md state the default.

## Where the default lived

- `kiln_abi::ReflectionMangling` (`crates/kiln_abi/src/mangle/reflect.rs`):
  `#[default]` moves from `Kiln` to `Gcc`. Everything that takes the
  enum's default follows: `kiln_driver::args::Args` (no flag means
  `gcc`), `AnonIds::new()`/`default()` (the mangler's tables outside
  codegen) and so sema's `type_order`.
- `CodegenOptions::default()` (`crates/kiln_codegen/src/lib.rs`) named
  `ReflectionMangling::Kiln` explicitly; it is now `Gcc`.
- `-help` (`crates/kiln_driver/src/help.rs`) lists `gcc (default)`.

## Fingerprints

The PCH option fingerprint (`kiln_driver/src/pch.rs`, "reflection
mangling") and the module-file fingerprint (spec/modules.md §11.4) both
read the `reflection-mangling` field of `pp_cmd`'s option list, which
spells the effective value of `Args::reflection_mangling`. A unit built
without the flag records `-fkiln-reflection-mangling=gcc`, as does a
consumer built without it, so they match. A PCH or BMI built by an
older kiln without the flag records `=kiln` and is refused as a
configuration mismatch; BMIs are unstable across releases anyway
(docs/STABILITY.md).

## `type_order`

`std::meta::type_order` compares the types' manglings, as GCC 16.1 does
(spec/reflection-traits.md). Sema mangles with a default `AnonIds`, so
`std::meta::info` now orders as `Dm` (before `int`, after a global class
`Z`), matching g++-16, whatever `-fkiln-reflection-mangling` says.
`meta.reflection.traits/type-order-mangling.cpp` checks it against GCC.

## Tests

- Pinned to `=kiln` (they are about the kiln form): every test in
  `kiln_codegen/tests/reflection_mangle.rs` (already passed the mode
  explicitly; docs updated), the `=kiln` leg of the driver's
  `two_translation_units_link`, and the new
  `expr.reflect/typeid-info-kiln-run.cpp` (`u6__info 1 1`).
- Re-blessed to the default: `expr.reflect/typeid-info-run.cpp` prints
  `Dm 1 1` and is now compared with GCC 16.1 (`oracle: gcc`);
  `two_translation_units_link` runs the default as the `Dm` leg;
  `gcc_link_compat` builds kiln's object without the flag;
  `per_kind_table` adds a no-flag pass that must equal the gcc column;
  `args.rs`'s unit test expects `Gcc` with no flag.
- `expr.reflect/reflection-mangle-gcc-run.cpp` keeps its explicit
  `=gcc`.
- `bench/`: no expectation names a symbol; the comments of
  `bench/frontend/reflection-mangle.cpp`, S9 (`xtask/src/gen_reflect.rs`)
  and spec/bench.md now say `L Dm … E`.
