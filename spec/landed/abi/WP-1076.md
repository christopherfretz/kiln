# WP-1076 — three clang test inputs that ran kiln past 20 s

WP-971's sweep over clang's test inputs found three files that kept kiln
busy for more than 20 s (30 s sweep timeout, debug build) while clang
finishes each in under half a second. None of them needed a new limit:
each was an algorithmic fault, exponential or quadratic, and is fixed at
its root. The rules live in spec/abi.md §8.22 ("Cost"), spec/ast.md §4.4
and §7, and spec/sema.md §4 (alignment across redeclarations).

## Linkage of a type built from a shared template-argument DAG

Inputs: `CodeGenCXX/pr29160.cpp` (36 copies of the previous level, 17
levels deep) and `CodeGenCXX/mangle-ms-back-references-pr13207.cpp`
(`A9 = Fooob<A8 × 10>`, nine levels; `B6`; and similar). The latter's
RUN line uses `-triple=i386-pc-win32`; kiln has no MS ABI, so it was
measured with the host's Itanium triple, which exercises the same
linkage queries.

- **Cause:** `kiln_abi::mangle::type_externally_visible`,
  `tag_externally_visible` and `args_externally_visible` (clang
  `getLVForTemplateArgumentList`), which codegen asks for every emitted
  function's parameter types and every specialization's arguments,
  recursed through every template argument without remembering any
  answer. A specialization whose arguments repeat one type walks that
  type once per path: 10^9 paths for `A9`, 36^17 for pr29160's `Q`.
  pr29160 reduced to 2/3/4 levels took 0.16 s / 1.78 s / over 60 s
  (×36 per level); callgrind on the 3-level reduction put the time in
  these three functions and the `decl_name` strings they allocate per
  visit.
- **Fix:** one query is a `Vis` walker with a memo keyed by canonical
  `QualType`: a class, enumeration, function or member-pointer type is
  walked once per query; pointers, references and arrays forward to
  their element without an entry. The public functions keep their
  signatures. Clang caches the same answer in the type
  (`Type::getLinkage` / `CachedProperties`).
- **Check:** the defined symbols and their linkage match clang++-19 for
  both inputs (45/45 and 3/3 names, zero difference).
- **Tests:** `tests/stress/linkage-type-dag-10x10.cpp` (`A9` and `B6`),
  `tests/stress/linkage-pack-dag-36x17.cpp` (pr29160 with `Base`
  defined), both `run` tests compared with the oracle.

## Merging many redeclarations of one variable

Input: `Preprocessor/bigoutput.c`, 16,384 `extern int x;` from nested
macros. Its RUN line is `-E`, which kiln already handles in 0.02 s with
output identical to clang's (229,516 bytes); the sweep's
`-x c++ -fsyntax-only` compile was the slow one.

- **Cause:** sema, for each new redeclaration, walked the whole
  redeclaration chain several times, so N redeclarations cost O(N²):
  - `align_redecl.rs` `merge_aligned_redecl` → `definition_before`
    (the earlier definition), for every redeclaration;
  - `visibility.rs` `finish_visibility_attrs` →
    `prior_visibility_attr`, even with no attribute or pragma to merge;
  - `Ast::inherited_attr` (`has_internal_linkage_attr`, asked twice per
    declaration) collected the chain into a `Vec` for an attribute kind
    nothing in the TU carries;
  - `decl.rs` `out_of_class_static_redecl` walked the chain twice for
    every variable, member or not.
- **Fix:** each walk now runs only when it can change the answer, so
  the results are unchanged:
  - the earlier definition is looked up only when the new declaration
    has an `alignas` of its own (the only use of it);
  - visibility merging returns early with no own attribute and no
    active `#pragma GCC visibility`, as the full path did;
  - `AttrArena` keeps a presence bitset per `AttrKind`, so `has_kind`
    is O(1) and `inherited_attr` returns `None` at once;
  - the static-data-member walks run only for a variable whose
    semantic context is a class (`CXXRecord` or a class template
    (partial) specialization).
- **Check:** the diagnostics of a set of namespace-scope and member
  redeclarations (const, `extern` with initializer, `auto`, `constexpr`
  out-of-class definitions of members of explicit specializations) are
  unchanged and match clang++-19.
- **Test:** `tests/stress/redecl-chain-65536.cpp` (65,536
  redeclarations; quadratic before, so well past the 120 s compile limit
  in the debug build CI uses).

## Timings

Harness-profile kiln++ (`cargo build --profile harness`), clang++-19
19.1, aarch64 Linux, `/usr/bin/time -f "%e s %M KB"`, peak RSS. Inputs
are the files under clang's `clang/test/` (the tree `cargo xtask clang-neg` reads),
unmodified.

| input | command | kiln before | kiln after | clang++-19 |
|---|---|---|---|---|
| CodeGenCXX/pr29160.cpp | `-std=c++20 -S -emit-llvm -o /dev/null` | >30 s (timeout), 12.7 MB | 0.08 s, 12.7 MB | 0.04 s, 89.7 MB |
| CodeGenCXX/mangle-ms-back-references-pr13207.cpp | same (host Itanium triple) | >30 s (timeout), 13.2 MB | 0.05 s, 13.3 MB | 0.02 s, 90.7 MB |
| Preprocessor/bigoutput.c (M14, 16,384 decls) | `-x c++ -std=gnu++20 -fsyntax-only -w` | 3.46 s, 11.5 MB | 0.06 s, 10.8 MB | 0.47 s, 85.2 MB |
| bigoutput.c with `M16` (65,536 decls) | same | 48.46 s, 18.8 MB | 0.11 s, 18.6 MB | 6.95 s, 93.2 MB |

Clang is itself quadratic on the M16 variant; kiln is now linear.
