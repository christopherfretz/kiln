# WP-1146 — member-like constrained friend template mangling

[temp.friend]/9; Itanium ABI `<unqualified-name> ::= F <source-name>`;
clang `isMemberLikeConstrainedFriend` / `getEffectiveDeclContext`. The
rule is spec/abi.md §8.16 "Member-like constrained friends".

- Sema records a friend template whose constraints name an enclosing
  class template's parameter (`friend_template_apart`) in
  `TemplateTables::member_like_friend` (template → class specialization;
  templ/member.rs `friend_function_template`). Its name gets `F`; from
  clang 20 its template prefix is the class's
  (`Mangler::member_like_friend_class`, `Mangler::parent`).
- A specialization instantiated from a friend declaration with a
  trailing requires-clause is nested even at namespace scope
  (`Mangler::member_like_spec`, `Mangler::name_in`); from clang 20 the
  template's first declaration must be a friend too.
- `AnonIds::with_clang_compat` selects clang 19's or clang 22's form; the
  codegen module passes `-fclang-compat`, the mangling differential
  (`mangle_vs_clang`, oracle clang 19) passes 19.
