# WP-479 — values and static storage: extract, reflect_constant*, P3491 define_static_*, refl_bytes

The value family of spec/reflection.md §3, contract in
spec/reflection-values.md.

- **Ops** (`crates/kiln_oven/src/meta/value.rs`, `ValueOp`; sema half
  `crates/kiln_sema/src/meta/value.rs`): `extract`, `reflect_constant`
  (and its `info` row), `reflect_object`, `reflect_function`,
  `__kiln_reflect_constant_string`, `__kiln_reflect_constant_array`,
  `__kiln_is_string_literal`, all `Stable`. The Oven freezes the
  operand into the content-interned constant store
  (`Oven::meta_freeze`, `meta_freeze_elems`; a range is read by layout,
  `elems_recipe`) and thaws a result into the call's result
  (`Oven::meta_value_out`: a scalar into the register, a class by copy
  into the result object, a reference as an address). Sema applies the
  structural and [temp.arg.nontype]/6 rules on the frozen value and
  picks the reflectee (§3 of the contract).
- **Library** (`tests/support/kiln_meta.h`, WP-479 block): the range forms
  of `reflect_constant_string`/`_array`, `define_static_string`,
  `define_static_array`, `define_static_object` and
  `std::is_string_literal`, as libstdc++ writes them over the intrinsics.
- **Accounting** (`crates/kiln_oven/src/meta/intern.rs`, `Memory::refl`):
  `refl_bytes` as spec/oven.md "Limits and metrics" states; a report
  field and an `oven:` counter (spec/harness.md).
- **Codegen** (`crates/kiln_codegen/src/consts.rs` `const_chars`,
  `fold.rs`): a frozen character array is a string-pool global; a
  constant initializer sema evaluated is emitted from its stored value.

Divergences from GCC 16.1 (kiln follows the IS): `reflect_function` of an
immediate function is rejected; `extract<const int*>` of a constexpr
reference variable and of the array it binds compare equal.
