# WP-478 — M6-09: member, access, layout and annotation queries

- **Member queries** ([meta.reflection.member.queries]; P2996R13):
  `members_of`, `bases_of`, `static_data_members_of`,
  `nonstatic_data_members_of`, `subobjects_of`, `enumerators_of`,
  `parameters_of` (`crates/kiln_sema/src/meta/member.rs`), returning
  `std::vector<info>` through WP-475's `Vector` recipe. A class's
  implicit special members are declared first (D4) and listed after the
  declared members in GCC 16.1's order; friends are not members; a
  namespace (`^^::` too) lists its first declarations across every
  block. Contract: spec/reflection-members.md §1–§2.
- **`MemberCache`** (`crates/kiln_oven/src/meta/member_cache.rs`): one
  list per (entity, list kind), immutable for a complete class, a
  growing prefix for a namespace (per-block cursors, declaration-count
  stamp); a query is one filtered copy into `Oven::meta_infos`.
  `tests/stress/meta-members-2000.cpp` holds 10,000 queries of a
  2,006-member class to `allocs<=10000` (one result vector each).
- **Access** ([meta.reflection.access.context], [.access.queries]):
  `access_context::current()` from the evaluation point's scope
  (`MetaCtx::scope`), `unprivileged`, `unchecked`, `via` (checked by
  `__kiln_access_via`), `current_function`/`_class`/`_namespace`,
  `is_accessible` and `has_inaccessible_*`
  (`crates/kiln_sema/src/meta/access.rs`), all on sema's access check:
  `Sema::member_accessible_in`/`base_accessible_in` over a stored
  `AccessScope` (`crates/kiln_sema/src/class/access.rs`).
- **Layout** ([meta.reflection.layout]): `offset_of` (`member_offset`),
  `size_of`, `alignment_of`, `bit_size_of` from `kiln_abi`'s record
  layout, so they equal `offsetof`/`sizeof`/`alignof`.
- **Annotations** ([meta.reflection.annotation]; P3394R4):
  `annotations_of`, `annotations_of_with_type` (`remove_const` of the
  type), `is_annotation` over WP-481's side table
  (`crates/kiln_sema/src/meta/annot.rs`), after `require_annotations`.
  One annotation attribute shared by several declarators is now one
  annotation (`Sema::annot_of_attr`, `crates/kiln_sema/src/annot.rs`).
- **Retired**: the spike's `__kiln_members_count`/`__kiln_member_at` and
  `reflect_members` (`crates/kiln_sema/src/meta/ext.rs`); the converted
  tests are `reflection/{queries,queries-neg,memo-purity,define-member}.cpp`
  and `expr.reflect/meta-kinds.cpp`.
- **Header** (`tests/support/kiln_meta.h`): the real declarations, plus
  `consteval` copy members on `std::meta::exception` and
  `access_context`'s constructor (a consteval-only type's functions must
  be consteval, WP-472).
- **Tests**: `tests/conformance/meta.reflection.member.queries/`,
  `meta.reflection.access.context/`, `meta.reflection.access.queries/`,
  `meta.reflection.layout/`, `meta.reflection.annotation/queries-*.cpp`,
  all `oracle: gcc` with a negative file per directory.
