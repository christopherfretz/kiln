# WP-1482 — g++.dg/reflect clusters: iterated ranges, extract of locals, evaluation point, linkage and parent

The rules are spec/reflection.md §3.5 ("Which ranges are read by
layout", "Iterating") and spec/reflection-values.md §5 ("Automatic
variables"). Found running GCC's C++ testsuite (`g++.dg/reflect`).

- **Range arguments were read from their layout only.** Every range
  argument of an intrinsic (`reflect_constant_array`, `substitute`,
  `define_aggregate`, …) was matched against a pointer-and-size or
  pointer-pair layout, so a fixed-extent `span`, `views::transform`,
  `filter`, `zip` and every input range were rejected, and a class that
  merely looked like a pointer pair could be misread. Now
  `Sema::range_by_layout` (`crates/kiln_sema/src/meta/iterate.rs`) admits
  only the standard contiguous classes; any other argument is
  `Shape::Iter` (`crates/kiln_oven/src/meta/materialize.rs`), its call
  compiles as an ordinary call (`Compiler::meta_iterates`,
  `crates/kiln_oven/src/compile.rs`), and the intrinsic's body,
  `Sema::meta_iter_thunk`, copies the range into a `std::vector` in one
  pass and calls the intrinsic with it. A test's struct that was read as
  a `(data, size)` range although it is no range
  (`reflection/substitute-trial-rollback.cpp`) now passes an array.
- **Explicit conversion functions in a copy-initialization.**
  `add_conversion_candidate` (`crates/kiln_sema/src/overload/ics.rs`)
  checked a non-viable explicit conversion function's constraints before
  dropping it, which recursed through `views::cache_latest`'s
  `view_interface::operator bool`; it now drops it first, as clang does.
- **`type_of` of a data member description** returns its type.
- **`extract` of an automatic variable** (`Sema::extract_local`,
  `crates/kiln_sema/src/meta/value.rs`; `Oven::meta_local`,
  `MetaOut::Live`): the innermost live instance in the current
  evaluation, else an error.
- **Evaluation point in a class template specialization.** A
  non-dependent immediate invocation in a template was evaluated once,
  in the pattern, and its node shared by every instantiation, so
  `access_context::current()` in `S<T>`'s static member gave `^^S`.
  `Sema::eval_immediate` (`crates/kiln_sema/src/consteval.rs`) now notes
  an impure evaluation in a template; such a value is not stored and
  `Sema::mark_point_dependent` marks the invocation, its call and its
  ancestors instantiation-dependent, so each specialization rebuilds and
  evaluates it. Pure invocations are stored and shared as before.
- **Anonymous unions and names.** `is_class_member`/`is_namespace_member`
  answer for a namespace-scope anonymous union's member as for the
  union's (`member_parent`, `crates/kiln_sema/src/meta/query/pred.rs`);
  `members_of` of the namespace lists the union's unnamed variable
  (`Sema::anonymous_union_object`, `crates/kiln_sema/src/meta/member.rs`);
  `data_member_spec` rejects built-in type trait spellings as keywords
  (`crates/kiln_sema/src/meta/define.rs`).
- **Deviations recorded** (docs/status/deviations.md): `is_variable` of
  `reflect_constant_array`; `main` and `static` functions in `extern "C"`;
  alias template and namespace alias linkage; locals of consteval blocks;
  GNU extended identifiers.
- **`if constexpr` in an instantiation.** The condition is substituted in
  a constant-evaluated context (`crates/kiln_sema/src/templ/subst/stmts.rs`),
  so `&&` short-circuits a failing consteval call.
- **Tests.** `meta.define.static/iterated-ranges.cpp`,
  `iterated-ranges-unsupported.cpp` (xfail: `bool` and array elements),
  `array-from-ranges.cpp` (xfail removed),
  `over.match.ref/explicit-conversion-constraints-not-checked.cpp`,
  `meta.reflection.define.aggregate/data-member-spec-type-and-names.cpp`,
  `meta.reflection.extract/local-variable.cpp` (xfail removed),
  `local-variable-neg.cpp`, `multidimensional-array.cpp`,
  `stmt.if/constexpr-condition-short-circuit-instantiation.cpp`,
  `meta.define.static/iterated-range-budget.cpp` (10,000 elements of a
  `views::transform`: Oven peak 105.7 KB, the same as building the
  vector by hand; the vector is reclaimed before the evaluation ends).
