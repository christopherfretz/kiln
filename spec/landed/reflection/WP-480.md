# WP-480 — define_aggregate and data_member_spec

The rules are spec/reflection.md §6.1 (`data_member_spec`), §6.2
(`define_aggregate`) and §6.3 (`__kiln_define_member`). This file records
what the implementation does beyond them, and the tests.

- **Where.** Sema: `crates/kiln_sema/src/meta/define.rs` (the `Define`
  family: options plan, the 13 checks, `define_aggregate`'s preconditions
  and `Sema::inject_field`, which `__kiln_define_member` in `ext.rs` also
  uses). Oven: `crates/kiln_oven/src/meta/define.rs` (`DefineOp`, the
  options decode, the content-interned `DmsTable`), `ty.rs`
  (provisional slots keyed by class, the completion epoch),
  `vm/meta.rs` (refresh after a `Mutating` op). `recipe.rs` gives
  `define_aggregate` the `Range` shape. `kiln_lex::is_identifier` is the
  lexer's own identifier test, exported.
- **Reading `data_member_options`.** The layout is found once per TU from
  `std::meta::data_member_options`'s members (`name`, `alignment`,
  `bit_width`, `no_unique_address`; an `optional`'s payload type is its
  first template argument) and cached; each leaf walk is cached by type.
  `name_type` is read as a `bool` form flag (when it has one) followed by
  a narrow-character pointer and a length, choosing the `char8_t` or
  `char` pair the flag names, so both `tests/support/kiln_meta.h`'s
  non-owning form and a two-string form read the same way. libc++'s and
  libstdc++'s owning `std::string` members are not read (unsupported).
- **Errors.** `data_member_spec` failures throw `std::meta::exception`
  with GCC 16.1's wording and order. `define_aggregate` failures are not
  constant expressions, reported where the consteval block is with the
  call's notes (the "in call to" note of the block's invocation
  included). A null reflection prints as `std::meta::info()`.
- **Injected members.** Each field is public, at the call's location,
  with the consteval block as its cold `injection_point`. A redeclaration
  or `__kiln_define_member` duplicate of one notes "member injected
  here". A bit-field width above the type's width warns as for a declared
  bit-field (`-Wbitfield-width`), except for `bool`.
- **Completion in the same evaluation.** `act_on_finish_record_definition`
  runs once, lending the Oven, and the Oven rebuilds the one provisional
  slot at once, so `sizeof`, `new C{...}` and member access in the rest
  of the block see the complete class. An explicit or implicit class
  template specialization is completed the same way (it keeps its
  specialization kind); so is a member class of a class template.
- **`-Wkiln-extension`** (`KilnExtension`, default on):
  `ext_kiln_define_member` on every evaluated `__kiln_define_member`
  call. The existing define-member and consteval-block tests pass
  `-Wno-kiln-extension`.
- **Report kind.** The constexpr report's `consteval_block` kind
  (spec/oven.md) is now accepted by `cargo xtask test`'s `oven:` budget
  reader (`xtask/src/util/oven_report.rs`).
- **Cost** (harness profile, reduced S3 with `kiln_meta.h`): the
  10,000-member `define_aggregate` takes about 5 ms of Oven time and adds
  about 3 MiB of RSS; 1,000 four-member struct-of-arrays definitions take
  about 5 ms. `data_member_spec` costs about 1.6 µs per call, most of it
  the generic by-value class argument and union-checked loads.

**Tests** (all `skip(clang)`):
- `tests/conformance/meta.reflection.define.aggregate/`: the standard's
  example (`spec-example.cpp`), description identity and kinds
  (`spec-data-member-spec.cpp`), every `data_member_spec` rule
  (`data-member-spec-neg.cpp`, generated, checked line by line against
  GCC 16.1; `data-member-spec-exception.cpp`), every `define_aggregate`
  precondition (`define-plainly-neg.cpp`, `define-class-neg.cpp`,
  `define-scope-neg.cpp`, `define-elements-neg.cpp`), layout
  (`define-layout.cpp`, `define-bitfield-width.cpp`), completion in the
  same evaluation and trials (`define-same-evaluation.cpp`,
  `define-trial.cpp`), `template for` over the members
  (`define-template-for.cpp`), the warning
  (`kiln-extension-warning.cpp`), and run tests for layout, mangling and
  aggregate initialization (`define-run-layout.cpp`) and a
  struct-of-arrays (`define-run-soa.cpp`). `define-run-soa-template.cpp`
  and `define-run-template-for.cpp` are `xfail(kiln)` until dependent and
  member splices (WP-474).
- `tests/conformance/reflection/define-member{,-neg,-run}.cpp`.
- `tests/stress/incomplete-classes-many.cpp` (5,000 provisional slots,
  10,000 evaluations) and `tests/stress/define-aggregate-10k.cpp`, both
  with `oven:` budgets.
