# Standard support

What kiln supports in each C++ standard, one row per core-language feature.
This is the single place to read kiln's language conformance; it is also the
M4 exit checklist ([ROADMAP.md](ROADMAP.md) M4: every C++23 row `done`, every
C++26 row `done` or carrying a written reason). The C++26 rows are the core
papers of C++26 as balloted: the working draft sent to the ISO DIS ballot from
the Croydon plenary (March 2026), whether or not clang 22 ships them (WP-706).
`cargo xtask features` checks the file mechanically (format and checks:
[spec/harness.md](../spec/harness.md), "Feature table"), including that the
summary below matches the sections under it.

Scope: the core language. Library papers (`__cpp_lib_*`) are out of scope
here; kiln compiles the platform's standard library rather than shipping
one, and the library picture is [status/libstdcxx.md](status/libstdcxx.md)
(GCC's libstdc++) and [status/libcxx.md](status/libcxx.md) (LLVM's libc++).

Each `gnu++NN` spelling is accepted too and selects the same language plus
GNU extensions. A row counts in the standard that introduced the feature;
later standards' changes to it are their own rows. `untested` rows (an
accepted feature with no corpus test of its own) count in neither `done`
nor `partial`.

Columns:

- **Paper**: the paper (`P<n>R<r>`, `N<n>`), core issue (`CWG<n>`), work
  package (`WP-<n>`, kiln extensions) or, for a baseline area with no single
  paper, its stable name (`[except]`).
- **Macro**: `` `__cpp_name` KILN / CLANG22 ``, several joined by `<br>`.
  KILN is `kiln++ -std=c++NN -dM -E`; CLANG22 is `clang++-22 -std=c++NN -dM -E
  -x c++ /dev/null` (22.1.8), where `c++NN` is the `-std=` the table's header
  cell names (`c++26` when it names none). `—` means the macro is not
  defined; a bare `—` means the feature has no `__cpp_*` macro of its own.
  Where clang 19 differs from clang 22, its value is in Notes (kiln's
  predefines are generated from clang 19, so they match it except where
  `apply_flags` raises a macro for a feature kiln implements: P0847's
  `__cpp_explicit_this_parameter` from C++23, P1061, P2893, P2747, P3068, P1306; the
  WP-357 ones are `KILN_FEATURES` in `crates/kiln_pp/src/predef.rs`).
  A `done` row's macros equal clang 22's; a row whose only gap is a stale
  macro is `partial` and listed under [Macro gaps](#macro-gaps).
- **Status**: `done` = kiln passes corpus tests covering the core forms;
  `partial` = some pass, or some are `xfail(kiln)`; `todo` = nothing passes;
  `untested` = no corpus test yet. The C++23 and C++26 rows were seeded on
  2026-11-01 (WP-185) and the C++98–C++20 rows on 2026-11-05 (WP-646), each
  from a corpus run through kiln.
- **Corpus tests**: paths under `tests/`. `*-probe.cpp` files are one-per-paper
  probes (WP-185 for C++23/26, WP-646 for C++98–C++20) written where no
  existing test covered the row; a probe marked `xfail(clang)` names the clang
  versions that lack the feature in its reason. Since the oracle switch
  (WP-355) a probe that only clang 19 lacks says `requires: clang>=22`
  instead, so it is a real two-compiler test under the clang 22 oracle and
  runs kiln at `-fclang-compat=22` under the clang 19 one.

## Macro gaps

kiln's `__cpp_*` set under `-std=c++26` is clang 19's, plus the P0847, P1061 and P2893 macros, `__cpp_constexpr` 202406L (P2747) and `__cpp_constexpr_exceptions` 202411L (P3068, which clang 22 does not define) `__cpp_modules` 1 from C++20 (clang 22's value; clang 19 does not define it) and `__cpp_expansion_statements` 202506L (P1306, which clang 22 does not define) and `__cpp_contracts` 202502L (P2900, which clang 22 does not define) and `__cpp_trivial_union` 202603L (P3074, which clang 22 does not define), so it differs from clang 22 as follows:

| Macro | kiln (= clang 19) | clang 22 | Row | Action |
|---|---|---|---|---|
| `__cpp_trivial_relocatability` | — | 202502L | P2786 (partial) | None: P2786R13 was removed from C++26 at Kona (Nov 2025), so kiln stays at clang's value (undefined) and the macro is exempt from the M4 C++26 exit (see the P2786 row). |
