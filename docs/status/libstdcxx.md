# libstdc++ header sweep

Every public header of the system libstdc++ (`/usr/include/c++/14`, GCC 14)
compiled as a one-line TU (`#include <header>`) with
`kiln -stdlib=libstdc++ -fsyntax-only`, next to `clang++-19` as the reference.
The tables between the `libstdcxx:<std>` markers are generated by
`cargo xtask libstdcxx --std <std> --report docs/status/libstdcxx.md`
(contract: [spec/libstdcxx.md](../../spec/libstdcxx.md)); the **Clusters**
section at the end is hand-written triage of those runs (WP-188, last refreshed WP-332) and must be
refreshed by hand when the numbers move.

Timings are a debug-profile kiln at `-j 2` on a shared host: compare runs, not
absolute numbers.
