# Rejecting invalid code: clang negative tests

How often kiln accepts a program that clang rejects, measured on clang's own
C++ `-verify` tests (`clang/test/CXX` and `clang/test/SemaCXX` at a pinned
llvm-project tag). Each test is run through kiln with every `expected-error`
made unmatchable, so kiln's verifier reports every error clang expects and every
error kiln emits, each with its line. Wording is never compared: an expected
error counts as reported when kiln has any error on that line. Contract:
[spec/clang-neg.md](../../spec/clang-neg.md); headline numbers in
[COMPATIBILITY.md](../COMPATIBILITY.md#rejecting-invalid-code).

Reproduce:

```sh
scripts/fetch-clang-tests.sh          # sparse checkout into .oss/clang-tests (about 50 MB)
cargo xtask clang-neg -j 4 --json scratchpad/clang-neg.json \
    --report docs/status/accepts-invalid.md CXX SemaCXX
```

The region between the markers below is generated; the triage after it is
written by hand (WP-912). The run is informational and never part of
`cargo xtask ci`.
