# z3 with kiln++ (WP-799)

z3 **4.15.8** (tag `z3-4.15.8`), built with kiln++ as `CMAKE_CXX_COMPILER`
through z3's own CMake build (the `shell` and `test-z3` targets), then
z3's unit tests (`test-z3 /a`) and the z3 shell on the SMT-LIB2 examples
of the source tree. The control is a clang++-19 build of the same tree
with the same flags. Host: aarch64 Linux, libstdc++ 14, C++20 (z3 pins
it), default `-fclang-compat`, Release (`-O3`). Date: 2026-11-07.

**Result: parity.** All 972 TUs compile, both targets link, `test-z3 /a`
passes, and the output of every test and example is the control's except
for timings. kiln needed five fixes: two for valid code it rejected and
three for symbols it left undefined at link time. No test failed at run
time once everything linked (no miscompile).

## Commands

```sh
source scripts/env.sh                          # shared jobserver for make
cargo build --profile harness -p kiln_driver   # $CARGO_TARGET_DIR/harness/kiln++
scripts/oss/oss-build.sh z3 --compiler clang
scripts/oss/oss-build.sh z3
scripts/oss/oss-report.py --perf z3
```

In `.oss/build/z3/<kiln|clang>/` (the wrapper `scripts/oss/kiln-cxx`
applies `ulimit -v 3000000` and `timeout 600`):

```sh
cmake --fresh -S .oss/src/z3 -B . -G "Unix Makefiles" \
  -DCMAKE_CXX_COMPILER=scripts/oss/kiln-cxx -DCMAKE_C_COMPILER=clang-19 \
  -DCMAKE_CXX_STANDARD=20 -DCMAKE_BUILD_TYPE=Release
nice -n 10 make -k shell test-z3      # draws from the shared jobserver
./test-z3 /a                          # 376 unit tests
for f in ../../../src/z3/examples/SMT-LIB2/*/*.smt2 \
         ../../../src/z3/examples/python/data/*.smt2; do
  timeout 10 ./z3 "$f"; done          # 9 examples
```

`test-z3 /a` prints one `(<test> :time … :before-memory … :after-memory …)`
line per test and exits non-zero on the first failure. The examples are
`bubble_sort`, `loop_unrolling`, `loop_unrolling_bitvec` and `horn1`–`horn6`;
their answers (`unsat`/`sat` per query, and models) are compared with the
control's. The whole test log (23,362 lines) is the control's once the
timing numbers are masked.

## Results

- **TUs** are z3's build-phase compiles (972, CMake probes excluded).
- **Wall** is the `oss-build.sh` run (configure, build and test), from
  `report.json`. Builds draw from a jobserver shared with other harness
  builds, so walls of different runs are not comparable; the summed TU
  times below are.
- **Peak TU RSS** is the wrapper's `ru_maxrss` for the compiler plus the
  backend it waited for.

| Build | TUs ok / failed | Links | Tests | Wall | Peak TU RSS |
|---|---|---|---|---|---|
| kiln, first (`45ccf9433`) | 622 / 2 (346 not attempted) | 0 / 0 | not built | 1168 s | 318 MB |
| clang++-19 (control) | 972 / 0 | 2 / 0 | 376/376, 9 examples | 1530 s | 415 MB (`src/smt/theory_arith.cpp`) |
| kiln, after cluster 1 | 820 / 1 (151 not attempted) | 0 / 0 | not built | 1543 s | — |
| **kiln, final** (`5b2aca092`) | **972 / 0** | **2 / 0** | **376/376, 9 examples, same answers** | 337 s | **317 MB** (`src/smt/theory_arith.cpp`) |

In the first build the two rejected TUs are in `libz3`'s `smt` object
library, so `make -k` linked nothing and stopped attempting the TUs behind
it. The final kiln binary (`5b2aca092`) predates the last fix of the work
package (`f1bcb5676`, an NRVO miscompile found by duckdb's tests); z3's
tests pass without it.

geomean kiln/clang-19 time **1.25x**, RSS **0.38x**; total 2121 s vs 1764 s; peak TU RSS 317 MB vs 415 MB.

No TU uses more memory under kiln than under clang (the highest
kiln/clang RSS ratio is 0.76, `theory_arith.cpp`), so there is no RSS
finding. The time ratio is highest on small TUs: 457 of the 927 that take clang-19 at least 0.5 s. are over 1.2x on time, all
of them below 2 s. The worst five:

- `$KILN/.oss/src/z3/src/util/fixed_bit_vector.cpp`: time 1.3 / 0.5 s = 2.49x, RSS 64 / 153 MB = 0.42x
- `$KILN/.oss/src/z3/src/util/scoped_ctrl_c.cpp`: time 1.3 / 0.6 s = 2.29x, RSS 64 / 150 MB = 0.43x
- `$KILN/.oss/src/z3/src/util/inf_s_integer.cpp`: time 1.3 / 0.6 s = 2.24x, RSS 61 / 152 MB = 0.40x
- `$KILN/.oss/src/z3/src/params/theory_pb_params.cpp`: time 1.1 / 0.5 s = 2.21x, RSS 63 / 147 MB = 0.43x
- `$KILN/.oss/src/z3/src/util/debug.cpp`: time 1.4 / 0.6 s = 2.20x, RSS 66 / 151 MB = 0.44x
